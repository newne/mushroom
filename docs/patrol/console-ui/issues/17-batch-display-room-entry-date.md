# 17. 批次显示翻转：库房 · 入库日期 为主

Status: implemented（2026-10-15；验收四条逐条核过，见 §4）
归属：前端
依据：会话决定 D12；ADR-0020（权威身份 =（库房号, 入库日期））
依赖：—

## 1. 交付物

1. 环境模式与历史模式的批次显示改为「**库房 · 入库日期**」为主，业务名（如 `mogu-107`）作**附注**
2. **入库值与历史列一律不动**（历史对账不能断）

## 2. 验收（缺一条不算过）

- [x] 页面主显示为「611 · 2026-09-30」这类形式（环境表 `611 · 2026-09-30（当前）`、历史下拉 `611 · 2026-09-04（BATCH-10）`）
- [x] 业务名仍可见（作附注；没映射就写"业务名未标记"，**不编**）
- [x] 筛选与对账仍按原有键工作（`batchKey` 一个字节没动，见 §4 的护栏）
- [x] **没有**任何写入侧改动（只改 `web/console/index.html` 的显示字符串 + 回归断言）

## 3. 不做什么

- 不改数据库里的批次值
- 不改派生规则（权威仍是库房 + 入库日期）

## 4. 实现与验证（2026-10-15）

**实现**（`web/console/index.html`）：

- 新增 `batchIdentity(row, fallbackRoom)` ⇒ `{ main, note }`：`main` = 库房号 · 入库日期，
  `note` = `batch_no`（`mogu-*`）。库房号优先用后端给的 `room_label`（旧编号会写成
  `607（原始 7）`——只给数字会让人以为是同一套编码），后端没给（老 analysis 镜像）才退回
  调用方知道的 zone，仍没有就只给日期（**不猜**）；`batch_no` 是 NULL ⇒ `note` 空串，**不编**。
- 环境模式的「批次对比」表：主行 `611 · 2026-09-30（当前）`，附注行 `mogu-107`
  （原来主行是业务名、附注行是"<入库日期> 起"——那一行现在是主行的一部分，信息没丢）。
- 历史模式的生产批次下拉：`611 · 2026-09-04（BATCH-10）`（原来 `库房 611 · 入库 2026-09-04 · BATCH-10`）。
- **入库值与历史列一律不动**：`batchKey`、`/api/rounds`/`/api/environment/batches` 的消费字段、
  `selectedBatchKey` 的取值口径全都没动；option 的 `value` 仍是原来那个三元组。
