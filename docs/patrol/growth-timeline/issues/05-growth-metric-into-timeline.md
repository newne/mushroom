# 05. （P1）长势指标接入同一条时间轴

Status: ready-for-agent
归属：后端（端点）+ 前端（叠加）
依据：docs/patrol/growth-timeline/spec.md
依赖：**测量管线接通**（`measurements` 有行）；端点侧依赖票 01

## 为什么它是 P1

现场实测：**`measurements` 0 行**，`/growth/room` 60 个框全部 `no_prev` ⇒ **"蘑菇变化"本身现在没有数据源**。
本票是把插座用起来，不是造数据。

## 交付物

1. 端点增 `metric=growth`：每节点每轮带 `growth`（簇级像素量 `H_profile_px` 与包相对 `rel_profile_height`），**缺即 null**
2. 前端把长势曲线叠到**同一条双刻度时间轴**上（与票 03 的视图复用）
3. 单框详情保留既有「生长曲线」卡，二者**同源**不打架

## 验收（缺一条不算过）

- [ ] 没有测量行时 `growth` **是 null**，页面**不画零增长线**（沿用既有卡的原则）
- [ ] 只有估算档时标注「估算（未验证）」，**不与已验证混算**（ADR-0025）
- [ ] 单位口径：本批**像素 / 包相对**，**不出现 mm**（mm 是后续专项）
- [ ] 同一时间轴上长势与环境**时间对齐**（同一 ts 语义）

## 不做什么

- 不做 mm 实际尺寸映射
- 不做预测/外推
- 不做同期基线（票 23）
