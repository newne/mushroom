# 03. 48 站位小倍数矩阵（12 列 × 4 层，与平面图同序）

Status: ready-for-agent
归属：前端 + 后端
依据：[docs/patrol/growth-timeline/spec.md](spec.md)
依赖：02（同文件，且复用端点与画法）

## 交付物

历史 tab 新增「时序总览」：**本批全部站位**按 layer/col 排成小倍数矩阵，每格一张 sparkline。

- 端点扩为**全站位矩阵**（一次拿回，不发 48 次请求）
- 状态色：灰 = 无数据、蓝 = 有帧、绿 = 上升、红 = 下降/异常
- hover 给出站位、轮次时间、帧数

## 验收（缺一条不算过）

- [ ] 格数 = **站位格数**（按 `grid.cols × grid.layers` 算，**不是死写 48**）
- [ ] 布局与平面图**同一套 col/layer 顺序**，现场一眼能对上位置
- [ ] 缺口**断开画**（连起来 ⇒ 变红）；`null` **不画成 0**（当 0 ⇒ 变红）
- [ ] 单次响应 ≤ 500 KB（48 站 × 本批天数 × 8 轮）
- [ ] 零新前端依赖（手写内联 SVG）

## 不做什么

- 不做单节点放大（票 04）
- 不做分位数带（票 05）
- 不改既有「生长曲线」卡
