# 10. 帽期窗口的帧级 `cap_state` 标记（时间盒）

Status: ready-for-agent
归属：算法
依据：会话决定；本批帽期样本是**时间盒**
依赖：—

## 1. 交付物

1. 在帽期窗口（本批后期）对帧做**帧级** `cap_state` 标记，把「可辨认帽」的样本池**先固定下来**
2. 产出可复算的帧清单 + 标记清单

## 2. 验收（缺一条不算过）

- [ ] 帧清单与标记清单可**复算**
- [ ] 窗口内覆盖到可辨认帽出现的时段
- [ ] 标记只做帧级，不越权替对象级判定

## 3. 不做什么

- 不在窗口外补标（样本会失真）
- 不生成虚构菌帽
