## 交付物（一票打通全链路）

在历史 tab 点一个站位 ⇒ 看到它**本批每一轮**的巡检覆盖轨迹：端点 → 页面 → 断言，一次到底。

1. **端点**：该站位在本批的逐轮格（`round_id` / `ts` / `has_frame` / `n_frames`），**缺即缺**
2. **页面**：按真实时间定位的轨迹；缺口断开；灰 = 该轮无数据
3. **断言**：无头回归覆盖上面两条语义

## 验收（缺一条不算过）

- [ ] 点任一站位，能看到**当前批次**（取 `/batches` 的当前批；611 = 2026-09-30 起）的逐轮轨迹
- [ ] x 轴是**真实时间**；缺轮次处**断开**
- [ ] 无帧的轮次**不是 0**（不画成"0 帧"的点或柱）
- [ ] 单次响应 ≤ 200 KB（一个站位 × 本批天数 × 8 轮）
- [ ] 端点**纯读**；不碰 TDengine（ADR-0026）

## 不做什么

- 不做 48 站总览（票 03）
- 不做长势指标（P1，**等测量管线接通再开票**）
- 不做刷选与筛选（票 06）
