## 业务分层归档建议

### 脚本层（src/scripts）

- `analysis`: 离线分析、报表输出。
- `processing`: 生产处理链路和批处理逻辑。
- `monitoring`: 可观测性巡检。

- `data` / `data_collection`: 数据查询、存储和采集。

## 结构规范（Google 风格对齐）

1. 命名清晰：脚本名使用动作+对象（如 `workspace_artifact_archiver.py`）。
2. 职责单一：每个脚本聚焦一个运维目标，避免“大杂烩入口”。
3. 函数短小：拆分为小函数并显式输入输出。
4. 可测可复用：核心逻辑与 CLI 参数解析分离。
