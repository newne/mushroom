# ADR-0024：测量标定与四量的权威口径

日期：2026-10-13
状态：建议（Chief 已批 A1/A2/A3，待环境官与巡检手复核）
相关：`fmc4030-camera-scan/spec.md` §5/§6、`env-analysis/issues/11-measurements-contract.md`、
`fmc4030-camera-scan/issues/09-angle-profile-and-framing.md`、ADR-0020

## 背景

`analysis.measurements` 长期 0 行，`measure_fn` 在生产装配里没接（`deploy/src/deploy/m1.py`
未传，`patrol/src/patrol/daemon.py:251` 默认 None），区间表与调控决策全堵在这里。
接线时有两处口径必须先定，否则"有数据"会变成"有错数据"：

1. **像素 → 毫米的权威来源**。仓库里并存两套：`src/segmentation/geometry.py` 用"菌袋外接框
   240×140mm + 二阶矩椭圆主轴"反推 `mm_per_px`；`measure/calib.py` 与
   `docs/patrol/fmc4030-camera-scan/spec.md:257` 要求每站位一次标定。仓库内**没有任何标定
   数据文件**（glob 无命中）。
2. **四个量在当前角度档下各自能不能测**。2026-10-13 口径：现役物理现状 = 平视单档
   `level0`；将来是否换角由现场作业决定，不预设。平视能看到整簇形态，但看不到菌盖轮廓，
   也看不到菌杆长度方向。

## 决定

1. **主口径 = 每站位 `mm/px`，由 `--mm-per-px` 传入（派生/可覆盖）**，与取景微调
   （`deploy/framing_wire.py`）**共用同一个数**，不引入第二个标定量。
   `src/segmentation/geometry.py` 的"菌袋外接框反推"降级为**旁证/交叉校验**：
   正交方向与透视方向的口径不同，把它当主口径会悄悄污染所有数字——它算出的比例在
   两个方向上不一致，而错误是**平滑的**，看图看不出来。
2. **检出层用无模型 baseline（`measure/baseline.py`），产出必须带质量标记**。
   它复用现役启发式分割线（`src/scripts/processing/run_segmentation_inference.py` 的
   HSV + 距离变换思路）的同一套前景判据，但用纯 numpy 重写：测量生产者跑在库房主机上，
   那台机器只有 numpy + Pillow，装不了 torch/cv2。**没有真值之前，任何精确数字都是假的**，
   所以全部行带 `baseline`，区间表只吃 `verified`。
3. **四量的字段级口径（单档平视）**：

   | 量 | 列 | 单位 | 口径 |
   | --- | --- | --- | --- |
   | 每天增长量 | 无列 | mm/天 | 派生量：对可靠的长度列按小时 floor 后差分 |
   | 菌簇范围 | 暂无列 | mm / mm² | 可算（平视投影）：垂直跨度/水平跨度/面积/投影径，先由 `aggregate_box` 承载，落库待票 11 |
   | 菌盖直径 | `mean_cap_mm` | mm | **不可测**：单档平视无对应角度档 ⇒ 恒 NULL + `no_angle_profile` |
   | 菌杆长度 | `mean_len_mm`/`p10_len`/`p90_len` | mm | **不可测**：同上 ⇒ 恒 NULL |

   **禁止**拿平视投影宽度冒充菌盖直径、拿画面横向像素长度冒充杆长（票 09 §5 同款约束）。
4. **换角即换口径**：将来换角生效日 = 数据口径分界；生效日前后不可直接比较，
   趋势图与区间表不得跨角拼接；届时本 ADR 的第 3 条要重写（45° 下盖径可得、杆长需投影补偿）。

## 后果

- 生产链路的"非零行"是**管道证据**，不是"测出来了"：验收标准 = `GET /measurements` 出现
  非零行（票 11 §7），且每行带质量标记；区间表继续空着，直到有 `verified` 行。
- `quality` 成为下游的硬门控：《区间表与决策层只吃 `verified`》。这条一旦落地，
  "0 行"与"一堆看着像真的假数"之间的差别由标记表达，而不是靠人猜。
- 标定数据仍然缺：`--mm-per-px` 今天只能靠现场给一个值或先用旁证交叉校验。
  在拿到真值之前，所有 mm 数字只用于**同站位跨时间的相对变化**，不能用于绝对尺寸判断。
- 质量门阈值（模糊/过曝）需要现场帧统计才能定：真机帧 S306 实测 `lapvar=70.8`，
  低于默认阈值 100 ⇒ 现役阈值会拒真机帧。这是待标定项，不许静默改默认值。
