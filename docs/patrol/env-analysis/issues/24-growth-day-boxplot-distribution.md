# 24. 按生长天数的分布（五数接口 + 前端箱线图）

Status: ready-for-agent
归属：后端 + 前端
依据：`docs/patrol/env-baseline/spec.md`（接口形状 / 落点）；D14 D16
依赖：27（回填）；与 23 共用同一套批次/生长天数键

## 1. 交付物

1. 新取数：**同房间最近 N 个批次的日级行**（现在不存在）
2. 接口给**五数**：min / q1 / median / q3 / max / n，按生长天数分组
3. 前端在环境模式**手写内联 SVG** 画箱线，**三面板**（温度 / 湿度 / CO₂）
4. 默认对比「**本批 vs 最近 1 批**」，可切换对比批次

## 2. 验收（缺一条不算过）

- [ ] x 轴 = **生长天数**；每组两条箱线
- [ ] 页面**不新增任何前端依赖**
- [ ] 五数关系成立（min ≤ q1 ≤ median ≤ q3 ≤ max）
- [ ] n<3 不画箱体并标「样本不足」
- [ ] 1366×768 上不溢出

## 3. 不做什么

- 不引图表库
- 不改既有 violin 管线（它绑死单房间单批次，另写）
- 不做日历天口径
