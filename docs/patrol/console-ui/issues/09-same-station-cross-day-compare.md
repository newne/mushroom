# 09 · 同一站位按天对比（积累期主线）

**Status:** implemented（2026-10-13）
**来源：** 用户 2026-10-13 新方向——当前重点是"优化巡检过程、清晰拍到各阶段长势，为后续测量和决策
积累数据基础"；历史模式最值钱的能力变成"同一站位跨轮次/跨天对比"。
**抽样维度由 Chief 钉死：按天，不按轮。**

## 为什么按天、不按轮

一轮实测约 **7 min 40 s**（470/462/457 s，`fmc4030-camera-scan/issues/10 §1`），一天约 8 轮。
取"最近 6 轮"只覆盖不到 20 小时，相邻帧几乎一样——**看不出生长**，而"一眼看出这株这几天
怎么长的"正是这个视图存在的理由。

## 口径

1. **固定当前选中站位**（拼图格 / 对比块 / 上一站下一站 / 方向键都能选中它）。
2. **每天取最接近参考时段的那一轮**：参考时段默认 = **当前选中那一轮的时刻**（"这一轮几点跑的就按
   几点比"），也可在卡上的选择器里改成固定时刻；"跟随当前轮次"是一个**真实选项**（`value="auto"`），
   否则用户回不到默认。
3. **跨 5–7 天并排**（默认铺 5 天，最多 7 天；`一天一块`，最新在前）。
4. 某天没有参考时段附近的轮次时，取该天**最接近**的一轮，并在块上挂"**邻近时段（这天没有更近的
   一轮）**"——如实标注，不假装准（阈值 90 min，`CMP_TOD_TOLERANCE_MIN`）。
5. **如实标注"当前是原图"**：一帧约 750 KB，卡上直说"每张都是原图（约 750 KB）· 缩略图服务
   到位后自动换源"。缩略图能力属服务端，票 08 已开给发版官，**我没动手**。
6. 点任意一块 = 看那一天的**完整图像**（就地显示在上面的详情区，不跳卡不滚动），并把轮次选中
   同步过去。
7. **与拼图/原图同一个筛选口径**：角度档筛着的时候，对比条只认那个档的帧；被筛掉的天挂
   "该角度档无帧"占位，不默默空白。

## 实现要点（都在 `web/console/index.html`，纯前端、不新增后端）

| 点 | 说明 |
| --- | --- |
| 取数 | 逐天串行 `GET /api/images?round_id=…&station_id=…&limit=20`；串行是刻意的——前台页面不该为一张对比卡同时开 7 条连接 |
| 图片地址 | 复用 `imageUrlFor()`，仍走 `/api/image` 同源代理（ADR-0003：页面不直连 MinIO，**不碰 cloud_url**） |
| 幂等护栏 | `compareStationId` + `compareTodOf`：同一站位 + 同一参考时段已有数据就不重复取（点击链路会先后进两次 `loadCompare`） |
| 角度快照 | 角度档在**发起取数时冻住**。否则"取的时候按 top45 找、渲染的时候按 top0 判"会出现中间态：同一批数据一会儿显示 2 张图、一会儿显示占位（联调实测） |
| 选中同步 | 点对比块会把 `hist.selectedRoundId` 同步过去——对比条最常见的用法是**同站换天**（站位不变），不显式同步就会停在旧高亮 |
| 落点 | 对比卡放在拼图**之下、卡内**，所以"换轮次先看到拼图"那条结构约束（票 07）不会被破 |

### 过程中踩到并已修的三个"假绿/假红"
1. **断言写反**：把"不许有 img"当正确行为，结果那条红线命中的正是**正确行为**
   （保留所选档、其余挂占位）。已改成正面断言：出现的每一张图都必须是所选档。
2. **set value 到不存在的选项**：`#angleSel` 只列当前数据里真实存在的档且会被重建，写一个
   当时不存在的档名（`top0`）赋值会被忽略、change 成了空动作 → 一条永远通过/永远失败的假用例。
   已改成"先读回真实档名再断言"，并加了一条"前提成立"断言。
3. **等条件满足不等于渲染完成**：`waitFor` 的判据本身撞上过渡态。已改成等"目标态"（占位 + 图同时
   出现）而不是等"hint 变了"。
