# 05. 库房分位数带：这一批整体在怎么长

Status: implemented（2026-10-16；验收四条逐条核过，见 §4）
归属：前端（**后端一个字没改**，理由见 §4.1）
依据：[docs/patrol/growth-timeline/spec.md](spec.md)
依赖：04（同文件）

## 交付物

把全部站位按轮次聚合，画**中位线 + IQR 带**——吸收单点噪声，回答"这批整体在怎么长"。

实施口径（票面留白处，2026-10-16 实施时定；**分位数带是冲着有值的量设计的**）：

- **每轮跨站位**聚合成一条带宽：样本 = **该轮有帧站位的 `n_frames`**，求 `p25 / p50 / p75`
  （线性插值分位，R-7 / numpy 默认那一套）。P0 的 `coverage` 每格只有 `has_frame`（布尔）与
  `n_frames`——**对一个布尔量算四分位没有意义**，所以带宽画的是"有帧站位这一轮各拍了多少张"。
- 另给一条**覆盖率线**：本轮有帧站位数 / 本轮参与统计站位数（参与统计 = 本批页面已知站位，
  与总览网格的站位格同源）。"拍到几个站"比"每站拍几张"更贴现场问题。
- **样本不足就不画**：`n < ROOM_BAND_MIN_N = 2` 的轮次不给任何分位值（更不写 0），
  在那一轮打「样本不足（n=X）」标记，**带在那里断开**；`n = 0`（一个站位都没拍到）
  是另一句话：「整轮无帧」，同样断开。
- **同源**：直接从票 03 已经拿回的本批矩阵（`hist.overview`）算——**不再发一次请求**，
  页面上也**不缓存**第二份聚合结果（每次重画从矩阵重算），所以与总览不可能各算各的。
- **P1 长势**：同一套带宽机制换 `roomBandValue()` 那一步即可（缺值仍走"不画"）；现在
  **不为它造数据**（页面里没有任何 growth 假值）。

## 验收（缺一条不算过）

- [x] **样本不足**时明确标"样本不足"，**不画成 0**（沿用既有空态语言）
      —— 阈值 **`ROOM_BAND_MIN_N = 2`**（一个样本的"四分位"就是它自己，画出来是假精确；
      少于两个站位也不叫"整体"）。n < 2 的轮次 **DOM 上连 `data-p25/p50/p75` 都不存在**
      （不是 `0`），只留一条虚线 + 「样本不足（n=1）」，说明行写
      「样本不足（n=1）：2026-09-12 10:00——那一轮不画分位数，带在这里断开」。
      一个站位都没拍到的轮次说「整轮无帧」；整批都没拍到帧 ⇒ 整卡空态
      （「本批还没有任何一个站位拍到帧」）+ 不画 SVG。断言：`[data-p25="0"]` 等**一个都没有**、
      分位属性**不存在**、两种标记的 title 与说明逐字、整批无帧时不画带（§4.3 第 3–5、12、17 条）
- [x] 中位与 IQR 与总览**同源**（同一次取数算出，不在页面上各算各的）
      —— `drawRoomBand()` 由 `drawOverview()` 调用（**同一次渲染**），样本集 = `hist.overview`
      （票 03 那一次 `/api/timeline`，不带 station_id）；**不缓存**聚合结果 ⇒ 与总览不会漂移。
      断言两条：① 换轮次来回重画两次 ⇒ 矩阵请求 **+0**（§4.3 第 10 条）；
      ② 12 个逐轮 n **由两边的 DOM 各自数出来**必须相等（带上 `data-n` vs 总览里
      `circle.ov-pt` 的条数，§4.3 第 6 条）
- [x] 分位数带上的缺口与总览**同时断开**
      —— 分段判据与总览同一批格点：某轮 n < 2（样本不足）或 framed = 0（整轮无帧）⇒ 带断在那里。
      断言用**同一个 ts** 钉：默认态带断在 `2026-09-12 10:00`，总览那一轮正是 S102 的灰块
      （§4.3 第 7 条）；变体态（假件把 `2026-09-11 10:00` 整轮抹掉）⇒ 带两段（0-1 与 4-5），
      总览那一轮两个站位都成灰块（§4.3 第 13/14 条）
- [x] 零新前端依赖
      —— 整张图是**手写内联 SVG**（`roomBandSvg()` 拼字符串，与前三张卡同一手法）；
      断言：页面 `script[src]` / `link[rel=stylesheet]` 数为 0、`#roomband` 里没有 canvas/img/iframe
      （§4.3 第 1 条）

外加票面留白处补的两条（口径见「交付物」，断言 §4.3 第 8、9/15 条）：

- **x 仍是真实时间**：x 一律走票 04 那**唯一一套** `mdScale(axis.t0, axis.t1)`；
  断言用覆盖率线 6 个点的相邻间距比 = 真实间隔比 `12:16:24:24:8`（按下标画会全相等）
- **覆盖率线**：每轮 = 有帧站位 / 参与统计站位（2/3 2/3 2/3 1/3 2/3 2/3）；
  **这里的 0 是真的 0**（这一轮拍到 0 个站）⇒ 它**不断开**（`null ≠ 0` 的另一半：
  真 0 也不许说成"没数据"）

## 4. 实施与证据

### 4.1 后端：一个字没改（为什么）

票 03 的 `/timeline` 已经一次拿回**本批**矩阵（`rounds[]` 共享轴 + `nodes[].points[i]` 对齐，
每格 `has_frame` / `n_frames`）。本票要的聚合（每轮 p25/p50/p75 + 覆盖率）**从这份矩阵就能算**，
所以选在页面上算——**不沿用 spec 里 `room_band[]` 那个服务端字段**：那是"再取一次数"的另一半，
而本票的验收恰好是"同一次取数算出，不在页面上各算各的"。多一个服务端聚合字段，就会多一份
可能与矩阵漂移的副本（还得为它做空样本 / 缺帧的 null 语义），**得不到任何现场可见的东西**。
`analysis/**` 一行未动 ⇒ 后端套件不跑（票面口径：只有改了 `analysis/**` 才跑）；
PG / TDengine 全程没碰。

### 4.2 页面（`web/console/index.html`）

- **卡片**：历史 tab 里新增 `#roomband`（「库房分位数带」），排在「节点放大」之后 `#rbnote` 说明行。
- **取数**：**零请求**。`drawRoomBand()` 由 `drawOverview()` 在**同一次渲染**里调用，
  读的是 `hist.overview`（票 03 的矩阵）；`drawRoomBand()` 自己不取数、也不缓存聚合结果。
- **纯函数**：`roomBandValue()`（取值 = 有帧的 `n_frames`；**没帧是 null 不是 0**）、
  `roomBandQuantile()`（分位的**唯一定义**：线性插值 R-7）、`roomBandRounds()`（逐轮聚合：
  `n / p25 / p50 / p75 / framed / seen / coverage / drawable / shortfall / blank`）、
  `roomBandSvg()` + `rbLabelRow()`（标签贪心排布）、`rbLegend()` / `rbFootnote()`。
- **画法**（`viewBox 920×232`，x 走票 04 那唯一一套 `mdScale(axis.t0, axis.t1)`）：
  ① 分位数泳道（IQR 带 + 中位线 + 每轮竖须）；② **覆盖率泳道**（**自己一根纵轴**：
  比率与帧数共轴是骗人）；③ 底部真实时间刻度（主）+ 生长第 N 天（次，`day` **只用端点给的**，
  页面不自己算）。
- **断开的三种、都不断成 0**：样本不足（n < 2）/ 整轮无帧（framed = 0）/ 分母未知（0/0 ⇒
  覆盖率 null）。而覆盖率里的 **0 不断**：那是"这一轮拍到 0 个站"的真 0。
- 阈值写在 `ROOM_BAND_MIN_N` 一处，图例、说明、断言都按它说话。

### 4.5 边界与交接

- 阈值 `ROOM_BAND_MIN_N = 2` 是**下限**不是标定值：现场要"更稳的"中位与 IQR，把它调大即可
  （调大以后样本不足的轮次会变多，带会更碎——这是有意的：宁可断开，也不摆一个看不出波动的带）。
  真机 48 站、每轮参与统计的站位远多于 2，所以默认阈值在现场几乎不会触发。
- 覆盖率的分母 = **本批页面已知站位**（配置表 ∪ 矩阵里出现的站位）：整批都没拍到过的站位
  也算在分母里，否则"48 个站只拍到 2 个"会被读成 100%。分母为 0（两边都空）⇒ 覆盖率是
  `null`（0/0 不是 0%），线在那里断开。
- **x 必须继续走 `mdScale()`**（票 04 §4.5 立的契约）：本卡与放大图、总览共用同一条真实时间轴。
- 票 06（时间刷选）进来时，本卡跟着 `hist.overview` 的口径走即可——**不要**为它另存一份聚合结果。
