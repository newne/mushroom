# 23. 同期基线接口（生长天数 × 同日时刻）

Status: ready-for-agent
归属：后端
依据：`docs/patrol/env-baseline/spec.md`（接口形状 / 状态 / 重算）；D7 D8 D9 D17 D18
依赖：27（回填）、批次清单对齐

## 1. 交付物

1. 只读接口：按「**生长天数 × 同日时刻**」给出**历史批次分布**，**逐批可见**
2. 状态词沿用既有信封风格，**只新增 `insufficient_batches`**；`cross_season` 走 **`flags`** 而非状态
3. 挂**每日链**（`BASELINE_AT`，排在区间表重算之后）＋ **批次变更时**额外触发一次
4. **已结束批次封版、当前批次滚动**

## 2. 验收（缺一条不算过）

- [ ] n<3 **不给带**，并明确标「样本不足」
- [ ] 逐批可见（不把多批揉成一条汇总带）
- [ ] 已结束批次的值**稳定不变**；本批**随数据增长**
- [ ] 空态给出原因（无可对照批次 / 无环境 / 从未计算）
- [ ] 跨季节在 `flags` 里可读

## 3. 不做什么

- **不动 `ranges`**（两者消费者不同，见 D9）
- 不做归因（只描述偏离）
- 不补邻近批次顶替
