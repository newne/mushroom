# 18. 环境模式泳道标签字体重叠修复

Status: ready-for-agent
归属：前端
依据：只读侦察（2026-10-15）定位到唯一确定性成因
依赖：—

## 1. 交付物

1. 泳道内两个标签的纵向偏移改为**从车道高度派生**，不再硬编码（车道高度被压缩后两者基线只剩 4px ⇒ 必然叠字）

## 2. 验收（缺一条不算过）

- [ ] 两个标签的基线间距 ≥ **14px**
- [ ] 在 **1366×768** 真机截图里不重叠
- [ ] 车道高度再次变化时**不会复发**（偏移随高度走）

## 3. 不做什么

- **不**顺手改另两处疑似溢出（缺真机截图，凭推断改会把没坏的地方改坏）——另出票
