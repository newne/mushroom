# 蘑菇系统开发进展汇报

汇报日期：2026-03-09

## 1. 当前总体进展

当前已上线三部分模型，分别为环境数据及操作数据分析模型、图像识别及检索模型、决策分析模型。整体上，系统已由基础数据接入与处理阶段，进入以模型能力建设和业务化应用为核心的阶段，初步形成了从数据采集、特征计算、分析判断到结果输出的完整技术链路。

在环境数据及操作数据分析方面，系统已能够对历史环境温度、湿度、CO2 等关键指标进行持续收集与分析，并结合批次产量等业务结果开展跨批次对比分析与可视化展示，用于支撑生长过程评估和批次差异识别。

在设备操作分析方面，系统已能够对不同批次、不同生长天数下各类设备的操作记录进行归集与分析，识别不同阶段设备调整策略的差异，为后续建立标准化调控经验提供数据基础。

在调节反馈分析方面，系统已能够关联每次设备操作后的环境温湿度短期与中期变化情况，分析调节指令与环境反馈之间的关系，从而为评估操作有效性和优化控制策略提供依据。

从整体技术架构看，系统已实现图片接入、对象存储、向量化计算、分析结果落库以及接口化输出的贯通。前端采集图片进入 MinIO 统一管理后，系统可将图像特征及分析结果写入 PostgreSQL 与 pgvector，并进一步通过定时调度、API 接口和可视化页面提供稳定输出，具备较完整的智能分析流程基础。

## 2. 已完成的核心功能

### 2.1 模型能力建设

当前系统已完成本地 CLIP 模型集成，可将蘑菇图像编码为 512 维特征向量，为图像表征、相似度计算和状态识别提供统一的底层表示。这一能力使系统从传统的图像存储与展示，升级为具备视觉特征计算与语义检索能力的分析平台。

基于向量化结果，系统已建立历史相似案例检索能力，可结合库房、批次、生长天数及环境上下文，对历史样本进行筛选与匹配。该能力的技术价值在于，通过引入历史经验参照，模型分析不再局限于单帧图像判断，而是能够在相似案例基础上提升状态识别与趋势判断的稳定性。

在生成式能力方面，系统已接入 LLaMA/LLM 模块，可对图像特征、环境监测数据和设备运行上下文进行综合建模，输出可读性较高的自然语言分析结果。相较于单纯标签分类或数值判断，该能力进一步提升了模型输出的可解释性和业务可用性。

在此基础上，模型输出已由描述型结果扩展至结构化决策建议。当前系统不仅能够对生长状态进行分析，还能够围绕温度、湿度、CO2、新风等关键控制参数生成辅助性调控建议。这表明模型能力已从图像识别逐步延伸至分析推理与决策支持阶段。

从架构层面看，系统已经形成图像特征、文本分析结果与环境参数联合参与计算的多模态分析框架。该框架能够更准确地贴合真实生产场景，为后续模型优化、规则增强和效果评估提供良好的技术基础。

### 2.2 模型能力的业务价值

从业务与技术结合的角度看，当前模型能力已体现出较明确的应用价值。首先，系统具备了稳定的图像特征表达能力，可将非结构化图像数据转化为可检索、可比较、可分析的统一表示。其次，系统已形成基于历史案例的辅助分析机制，能够在当前状态判断中引入历史经验参照。再次，模型输出已具备一定的决策支撑属性，能够为实际生产调控提供参考依据。

因此，当前系统对外呈现的已不只是单一的识图能力，而是一个具备图像理解、案例匹配、分析生成与辅助决策能力的智能分析体系。这也是现阶段最能体现项目技术实力与后续落地潜力的部分。

### 2.3 支撑模型落地的系统能力

为支撑上述模型能力稳定运行，系统层面已完成相应的工程化建设。目前已提供 FastAPI 接口，用于对外暴露决策分析状态、监控点信息、图文质量及产量相关结果；同时提供 Streamlit 可视化入口，便于业务侧进行结果查看与验证。调度器部分已完成模块化重构，可按预设周期自动执行建表、环境统计、CLIP 推理和决策分析等任务。此外，系统保留命令行工具用于运维调试与批量处理，整体已具备较好的交付与扩展基础。

## 3. 当前阶段成果判断

从当前开发状态来看，项目最有代表性的进展在于模型能力已经具备初步业务化条件，不再停留在单一算法验证阶段，而是开始向“可调用、可解释、可嵌入流程”的方向推进。

更重要的是，模型主链路已经基本贯通。当前系统能够从图片输入出发，完成特征提取、相似匹配、文本生成和结果输出，形成较完整的智能分析流程。CLIP 与 LLM 也已从单点能力演进为协同工作框架，这为后续客户演示、试运行验证以及模型效果持续优化提供了明确基础。

## 4. 下一步工作重点

下一阶段建议继续围绕模型能力深化推进。一方面，需要进一步建立模型输出与实际生产结果之间的验证闭环，持续提升建议结果的可信度和可用性；另一方面，需要优化提示词设计、规则约束与结构化输出质量，增强模型结果的一致性与稳定性。同时，还需提升批量推理能力、系统稳定性和结果可解释性，为后续更大范围部署应用奠定基础。

## 5. 汇报结论

总体来看，当前项目最具代表性的阶段成果在于模型能力已基本成型。系统不仅能够完成图像数据处理，还已具备图像理解、历史案例匹配、分析结果生成与辅助决策输出等核心能力，整体已从数据处理平台演进为具备智能分析特征的业务支撑系统，并具备进一步验证、优化和推广落地的基础。
