# 07. 数据划分的分组键改为按巡检轮次

Status: ready-for-agent
归属：算法
依据：`docs/patrol/growth-algo/spec.md`（缺口 G8：规格自身冲突）
依赖：—

## 1. 交付物

1. 分组键从「周期 × 锚点 × 时间块」升到**含巡检轮次**：同一轮全部站位必须同侧
2. 若确实要「未见锚点」测试，测试锚点连同左右**相邻锚点**一起进测试侧
3. 新增断言：相邻锚点不得跨划分

## 2. 验收（缺一条不算过）

- [ ] 断言 `no_adjacent_anchor_leakage()` 有测试且**改坏了会红**
- [ ] 同一轮次的帧**不跨**训练/测试两侧
- [ ] 划分可复算

## 3. 不做什么

- 不改变「按组不按图」的原则（那是既有正确决定）
