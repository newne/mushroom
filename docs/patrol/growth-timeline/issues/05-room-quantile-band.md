# 05. 库房分位数带：这一批整体在怎么长

Status: ready-for-agent
归属：前端 + 后端
依据：[docs/patrol/growth-timeline/spec.md](spec.md)
依赖：04（同文件）

## 交付物

把全部站位按轮次聚合，画**中位线 + IQR 带**——吸收单点噪声，回答"这批整体在怎么长"。

## 验收（缺一条不算过）

- [ ] **样本不足**时明确标"样本不足"，**不画成 0**（沿用既有空态语言）
- [ ] 中位与 IQR 与总览**同源**（同一次取数算出，不在页面上各算各的）
- [ ] 分位数带上的缺口与总览**同时断开**
- [ ] 零新前端依赖

## 不做什么

- 不做跨批对照（env-analysis 票 23）
- 不做导出
