## 4. 口径分界（写死，与选哪个方案无关）

1. **换角生效日 = 数据口径分界**：生效日**之前/之后**的图像与派生量**不可直接比较**；
   **跨角比较一律禁止**——趋势图、区间表不得把两种视角的数据拼成一条趋势。
2. 换角后**必须按此顺序**重做（反序 = 照片顶着新标签名、实际是旧视角的像）：
   支架作业 → **分角锁焦/固定曝光** → **重扫 z（抓图链路 capture，不用 preview，
   §10.3 第 2 条：两者成像不能逐像素互推）** → 改 `GRID_ANGLES` + `reanchor` → trim 重学 →
   跑一轮 + 按层联系表复核（`round-sheet.py`）。
3. **换角后，测量侧"平视缺测"那条要重写**：45° 下**菌盖直径可得**（取横跨倾轴方向宽度，
   球冠/圆盘假设下投影不压缩），菌杆长度需投影补偿；顶拍只给菌盖直径。归属：**测量师**。
4. **现役平视单档下**：测量侧必须以"**缺测/该量不可测**"显式表达，**禁止静默降级**
   按平视图硬算充数；我这边保证图像索引里的 `angle_profile` 是**真值**（现为 `level0`，已真）。

## 6. 45° 的几何（**未验证的先验**，换角到 45° 时才需要）

盖径取**横跨倾轴方向**宽度（球冠/圆盘在该方向投影不被压缩，沿倾轴方向压 cos45°≈0.707）；
杆长沿倾轴方向量取 ×1/cos45°(≈1.414) 补偿。**需现场用已知尺寸靶标验证**，且依赖
菌盖近似轴对称这一假设。
