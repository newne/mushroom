# 04. 库房分位数带 + 时间刷选与筛选交互

Status: ready-for-agent
归属：前端
依据：docs/patrol/growth-timeline/spec.md
依赖：02

## 交付物

1. **库房分位数带**：把全部站位按轮次聚合，画中位线 + IQR 带（吸收单点噪声）
2. **时间刷选**：拖拽选段时间 ⇒ 总览与放大视图同步聚焦
3. **筛选**：按层 / 按列 / 按"有没有数据"筛（沿用既有 `data-station-filter` 手法）

## 验收（缺一条不算过）

- [ ] 分位数带在**样本不足**时明确标"样本不足"，**不画成 0**（沿用既有空态语言）
- [ ] 刷选后总览与放大视图**同源同步**，不各算各的
- [ ] 筛选后格数变化正确，且**不隐藏"被筛掉"的事实**（要有计数）
- [ ] 零新依赖

## 不做什么

- 不做跨批对照（票 23）
- 不做导出
