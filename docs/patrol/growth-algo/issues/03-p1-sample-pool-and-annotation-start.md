## 1. 池子构成（可复算）

| 分层 | 帧数 | 选法（不用人挑，全由规则决定） |

## 2. 开标顺序

1. **P01–P03 试画**（半天内）：先验配置与回读，**这 3 张不过就不开大批**；
2. **P04–P13 困难样本**：2 人**独立**各标一遍（算双人分歧）；
3. **P14–P68 锚点覆盖**：按层/列分工，每人固定一组站位（避免同帧被两人重复标）。

## 3. P1 通过判据（四条，缺一条不算过）

1. **试画回读**：3 个 XLABEL JSON 过票 `02` §6.2 四条（对象数与类别一致 / 几何容差 / **属性逐条一致或显式丢失清单** / 坐标恒 2880×1616）；
2. **双人分歧可算**：≥10 帧双标，分歧率与仲裁规则写回本票（**只看一袋一簇归属与簇顶轮廓**两项）；
3. **一袋一簇**：每帧「簇数 = 可测袋数」，跨袋/粘连一律 `association_valid=false` 且**行保留**；
4. **属性可回读**：`rejected`/`human_added` 行都在（删行 = 洗白假阳）。

## 4. 资源（一句话）

**P1 只标 68 帧、不训练**（人工 ≈8–15 min/帧 ⇒ 约 10–17 人·h，2 人并行 1–2 天）；
**训练预算：~500–800 帧（P4 扩），单张 ≥16 GB 显存 NVIDIA 微调 YOLO26s-seg ≈3–6 GPU·h + 调参 ≈1–2 GPU 天**——
现场机 4 核无 GPU、WSL2 也无 GPU，**CPU 训不划算**（帧数与机器需 Chief 定）。
