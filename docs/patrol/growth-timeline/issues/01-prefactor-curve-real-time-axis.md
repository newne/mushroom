# 01. 前置：既有「生长曲线」卡的 x 轴改为真实时间戳

Status: implemented（2026-10-16；验收四条逐条核过，见 §4）
归属：前端
依据：[docs/patrol/growth-timeline/spec.md](spec.md)
依赖：None（可立即开始）

## 为什么它是前置

**让改动变容易**：把"时间轴约定"先在一张**已有**卡片上立起来——真实时间戳定位、缺口断开、`null ≠ 0`。后面的 02–06 全部复用这套约定，不必各自发明一遍。

现状硬伤：那张卡用**数组下标**当 x（`i * step`）⇒ 巡检间隔不规律时，图上的"等距"是假的。这正是"从时间维度看"必须修掉的东西。

## 交付物

1. x 由**真实时间戳**定位：同一时间窗内，间隔不等的点按**真实比例**排布
2. 相邻两点之间**没有中间轮次**时**断开**（不直连）
3. 缺口不插值、不补零

## 验收（缺一条不算过）

- [x] 两个时间间隔差约 3 倍的点，图上水平间距也差约 3 倍（把 x 改回等距 ⇒ 断言变红；实测 3.00:1，改回下标 ⇒ 1.00:1 变红）
- [x] 中间缺轮次处是**两段断开的线**（连起来 ⇒ 断言变红；实测 4 个点 / 2 段线，改直连 ⇒ 1 段线变红）
- [x] 无测量行时仍是既有空态，**不画零增长线**（沿用该卡已有原则；那条断言一个字没动，仍绿）
- [x] 零新前端依赖（只用内建 `Date.parse` + 手写内联 SVG）；无头回归 412/421，新增 4 条全绿，失败 9 条与基线**逐条同名**

## 不做什么

- 不改这张卡的位置与定位（它仍是单框详情入口）
- 不动其他卡片

## 4. 实现与验证（2026-10-16）

**实现**（`web/console/index.html`：只动 `drawCurve()` + 4 个新助手，卡的位置/定位与其他卡片一个字节没动）：

- **x = 真实时间戳**（硬规则 1）：窗口取这只框自己的测量窗口（首行 ts → 末行 ts），
  `X(ts) = padL + (ts - t0)/(t1 - t0) · 可视宽`；`i * step` 那版删除。窗口宽为零（只有一轮 /
  同一时刻）才落回中间——那时"比例"没有定义。轴两端标签跟着窗口走。
- **缺口断开**（硬规则 2）：`curveSegments()` 把测量行切成段，**一段一条 `<path>`**，段间不连线
  （单点成不了一段线，交给圆点）。缺口判据两条，任一成立即断开：
  ① 中间夹着的测量行该量是 `null`——"这一轮没测到"；
  ② 中间夹着**轮次表里的轮次**（`hist.rounds` 同批次、带 `round_id`；无 ID 的旧轮次不猜测归组，
     与拼图同一口径），而这只框在这些轮次上没有可用的数（连"没测到"的行都没有）。
  不插值、不补零。
- **`null ≠ 0`**：`rowHasValue(row, key)` 只认 `typeof === 'number'`；三种空态
  （一行都没有 / 没有可用量 / 查不到 prod）三条分支一个字没动。
- **零新依赖**：只用内建 `Date.parse`；SVG 仍是手写内联。

新增 4 条断言：

**边界（写给 02–06 复用同一约定时）**：这张卡手里只有"这只框的测量行 + 批次轮次表"，
所以"缺口" = **这一轮没留下可用的数**。若整段时间一次巡检都没发生（连轮次都没有），本卡无从
判定"缺"，图上是宽空档但线仍连着；02 的 `/timeline` 给出逐轮格点后，判据只剩"这一格有没有值"
（`has_frame:false` 的格点自己就断开）——是同一套约定的加强版，不是另发明一套。
