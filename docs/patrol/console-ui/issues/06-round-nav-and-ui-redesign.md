# 04 · 轮次切换与两处界面改版（历史 / 环境）

**Status:** resolved（2026-10-13 上机）
**来源：** 2026-10-13 用户反馈
> 优化历史和环境 table 展示界面，当前布局不够易用、美观和科技感；历史 table 在上一站、下一站中
> 增加切换巡检轮次的按钮，同时剔除巡检失败全是空的轮次；切换轮次后默认显示拼接的图像即可，
> 可以直观看到整体生长情况；点击对应位置查看某一位置详细图像；环境 table 需要重新设计图像和布局，
> 当前图太大了，且文字窗格布局没有重点。

## 历史模式

1. **轮次切换按钮**（拼图卡上，与"站内翻页"分开摆）：`‹ 上一轮` / `下一轮 ›`。
   索引 0 = 最新，所以"上一轮"= 更早；到两端时按钮置灰，并给一句人话（"已经是最早一轮"）。
2. **剔除空轮次**：`n_results <= 0` 的轮次不进列表、也不占"上一轮"的一步。
   **字段缺失当作"不知道"而不是空**——老轮次没这个字段时不能把它们全藏起来（那样会静默丢历史）。
   跳过几个会在 `#roundinfo` 里说出来。
3. **落点是拼图**：拼图卡提到 `#hmain` 第一张（DOM 顺序 = 视觉顺序仍然成立），
   换轮次会清掉上一轮选中的站位并滚到拼图卡——先看整体生长情况。
4. **点格位看细节**：点拼图格位 → 大图有 src，并自动滚到大图卡（从整体到细节的一步）。

## 环境模式

1. **结论先行**：新增 KPI 磁贴（温/湿/CO₂ 中位 + 区间、采样点数、断档、补光折算），
   异常项（断档 / 整列无源）用 warn/bad 配色顶出来。
2. **图缩小**：车道 76 → 54、上下留白收紧，viewBox 高度 280 → 204（同样三个量仍各占一根轴，
   缩的是高度不是信息）。
3. **文字窗格立重点**：6 列分位数表换成"一行一个参数"——中位值放大加粗、
   区间退到次要位置、IQR 用一条横条表示离散程度；卡片标题加一道竖线便于扫读。

## 第二轮（2026-10-13 上午，用户跟进）

> 历史 table 不需要站位（按层）这一栏，巡检拼图放到当前栏位最大，巡检拼图不需要单独的预览大图，
> 点击对应位置能在旁边显示完整图像即可。

1. **站位（按层）那栏在历史模式让位**：`main.histmode`（与 envmode 同一套做法），
   中栏吃满——拼图才有地方变大。`main.histmode` 特异性高于任何 `main{...}`，
   所以窄屏（≤760px）必须自己再收一次，已在同处写了媒体查询。
2. **拼图吃满栏位**：格子大小由 JS 按容器实际宽度算（48–104px），
   上限 104 是刻意的——再大就得横向滚，反而看不全一屏；jsdom 没有布局（clientWidth=0）
   时退回 64px，所以断言仍按"格位数"写而不是像素。
3. **不再单开"大图"卡**：完整图像移到拼图**旁边**的 `#detailpane`（sticky，`object-fit:contain`
   看全图），点格位就地显示，不跳卡也不滚动。站位翻页按钮保留在这个窗格里。
4. **修掉一个撞 id 的 bug**：上一轮我把轮次信息写成 `#roundinfo`，而页头**已经有一个**
   `#roundinfo`（实时模式的"第 N/M 站"，由 renderOps 写入）。`$()` 取第一个匹配，
   于是轮次信息实际写进了页头。现改为 `#roundnavinfo`，并加了一条断言钉住
   "轮次信息不会写进页头"。

## 第三轮（2026-10-13 中午）

> 缩略图不需要显示下面的位置和时间。

格子就留那张图：去掉 `<b>站位号</b>` 与时间那行，缩略图改成 `aspect-ratio:16/9` 自己定高，
格子不再为"两行文字"预留高度（`min-height` 撤掉）。**但保留一种小字**：图在、状态却不正常时
（采图失败 / 本地待同步）挂一行——那行是现场要看的信号，不是冗余的位置时间。
位置与时间仍写在 `aria-label` 里，读屏照旧拿得到（视觉上没有≠信息没有了）。

## 第四轮（2026-10-13 中午）

> 图片还是太小，预览图和大图看不清细节，大图放预览图上门。（"上门"= 上面）

1. **大图挪到拼图上方、吃满整栏**：原来的左右分栏（大图只占 260–340px）是"看不清细节"的主因。
   现在图像区 `height:clamp(260px, 62vh, 720px)`、容器 flex 居中、图 `object-fit:contain`——
   1080p 屏上大约按 1190×670 显示，接近相机原图 1280×718，菌盖边缘看得清。
   缩放/拖拽按钮留在图下（放大后看细节仍走这条路）。
2. **缩略图放大**：格子上限 104 → 156px（1920 宽的屏上约 123px/格，原来约 104px），
   下限 56px。仍然按栏位宽度算，超宽才横向滚。
3. **DOM 顺序 = 视觉顺序**：`#detailpane` 在 `#timeline` 之前，并加了断言钉住
   （用 compareDocumentPosition 判，不靠读 CSS）。
