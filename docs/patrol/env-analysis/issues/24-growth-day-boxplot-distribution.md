# 24. 按生长天数的日分布视图（五数落库 + 前端箱线）

Status: implemented（2026-10-21；后端五数落库 + 每日任务 + 前端日分布图；1366×768 未上机核过，见 §2）
归属：后端 + 前端
依据：`docs/patrol/env-baseline/spec.md`（分布视图）、`docs/patrol/env-analysis/spec.md` §3、**ADR-0027**
依赖：无（原「对比历史批次」部分依赖 27 回填，2026-10-21 起**已砍掉**）

> **2026-10-21 改写**：原票定的是「本批 vs 最近 1 批」双箱线（D14）。用户裁定
> 「实测环境按天显示**本批次**所有数据即可」⇒ 跨批对比移出本票，见 ADR-0027。
> 同时把「小时均值曲线」合进同一张图、共用一根纵轴（不做双轴）。

## 1. 交付物

1. **派生表 `environment_daily`**：按 `(zone, 天)` 存三参数五数（**小时口径**）+ 采样点级极值
   + 采样点数/小时点数 + 该日补光制度摘要。
2. **重算 `analysis.env_daily.refresh(conn)`**：读 `environment` 小时行 → 按天分组 → 写表；
   挂每日任务（`DAILY_AT`）。**不封版**：每晚全量重算、按库房整删整写。
3. **接口 `GET /environment/daily`**：`state` 三态（`ok` / `never_computed` / `no_environment`），
   空窗口返回空数组 + 状态，**不返回伪造的 0**。
4. **前端三图**（温 / 湿 / CO₂）：手写内联 SVG，每张图四层共用一根纵轴——
   日箱线（小时口径）、中位数折线、小时均值曲线、采样点级极值淡带。
5. **光照制度带**：不画箱线，按循环制度设定变化点切段。

## 2. 验收（缺一条不算过）

- [x] x 轴 = **生长天数**（内部 D0 起）；无批次的那几天退回日历日期
- [x] 轴止于**最后一天有数据的日子**；落后 ≥2 天时在图上写明「数据止于 X」。
      **不猜「停采」**——停采与否由批次卡的 D 天与面板 `InDayNum` 说，日分布只对自己看到的行负责
- [x] 页面**不新增任何前端依赖**
- [x] 五数关系成立（`min ≤ q1 ≤ median ≤ q3 ≤ max`）
- [x] n<3 不画箱体，改画空心点并在图注说明
- [x] 采样点级极值带与箱线**视觉通道分开**，图注写清各自粒度
- [x] **不出现第二根纵轴**
- [x] 缺天不补：没有数据的一天不画箱体，也不插值连线
- [x] 区间参考带不叠在箱线上
- [ ] **1366×768 上不溢出**——未上机核过（本机没有可跑的 console 环境，见 deploy 侧 pyuv 编译失败）

## 3. 不做什么

- 不引图表库
- 不做跨批对比（ADR-0027）
- 不做日历天口径（日历日期只作次刻度）
- 不改既有 violin 管线（它绑死单房间单批次，另写）
- 不对光照做箱线（主口径是循环制度）
