## 为什么不能只用全局绝对阈值

真机帧 S306 实测：纯灰度、**强晕影**（中心亮、四角近黑）、平视单档、矮菇**低纹理**
⇒ `laplacian_variance = 70.8`，低于现默认 100。这个场景里 `lapvar` 天然偏低，
**全局常数必然误杀**：调小会放进真糊帧，调大会把所有帧都标成不可用（区间表继续空，
只是换成了"诚实的空"）。

但**也不能没有绝对兜底**：完全无信息量的帧（灯没亮、镜头盖着、传输拿到空图）
必须被硬拦——它不能只靠"相对基线低"来判，因为基线本身可能也是黑的。

## 决定（待批）

### 1. 判据分两类

| 类别 | 判据 | 参照 | 用途 |
| --- | --- | --- | --- |
| **相对** | 清晰度 `lapvar`、亮度 p99、过曝占比 | **同站位 + 同角度档**的**近窗历史基线** | 判"这一帧相对本点位正常水平是否异常" |
| **绝对兜底** | 亮度 p99、过曝占比（不涉及纹理） | 硬件物理下限（灯全灭/全白） | 拦"完全没有信息量"的帧 |

**关键取舍**：清晰度（有纹理的判据）**只用相对**——因为纹理量随生长阶段变化，
绝对阈值会把"菇还没长出来"的正常帧判成糊。亮度与过曝**两者都要**：相对管漂移、
绝对管无信息量。

### 2. 基线怎么来

- 键：`(station_id, angle_profile)`；**不含 `box_id`**（站位是成像单元，框是归属单元；
  同站位今天只服务一个框，将来一站位多框时基线仍按站位算才对）。
- 统计量：近窗 **N = 30 帧**（或最近 7 天，取先到者）的 `lapvar` 与 `p99` 的
  `median` 与 `MAD`（中位数 + 绝对中位差，抗少数坏帧污染）。
- 何时可用：该键**已有 ≥10 帧**历史 ⇒ 基线可用；
  **< 10 帧 ⇒ 返回"无法判定"**，处置见 §3 阶段一。
- 基线**不落库到 analysis**（它是产者的瞬时状态，不进 measurements 契约）；
  由装配侧每轮从近窗帧算一次并注入。

### 3. 处置（三级，不接受"降权进统计"）

| 情形 | 处置 | 标记 |
| --- | --- | --- |
| 相对判据说异常，但帧有信息量 | 产行，**不进统计** | `low_confidence`（+ 原因） |
| 绝对兜底命中（无信息量） | **不产行** | 门拒绝（`no_light` 等） |
| 相对正常 + 绝对正常 | 产行，可发 `verified`（**仍需人工看图确认那批**，见票 13 风险） | — |

**为什么异常帧仍然产行**：Chief 已定"门只决定 `verified` 的授予，不决定入库"——
留在库里可审计、可回溯，只是不进区间表。

### 4. 分三个阶段落地（每阶段都有明确验收）

| 阶段 | 条件 | 行为 |
| --- | --- | --- |
| 一 | 基线不足（每站位 <10 帧） | **绝不发 `verified`**；帧照常入库：可测的标 `low_confidence`，绝对兜底命中的不产行。宁可没有 `verified`，也不发错的 |
| 二 | 基线可用 | 相对判据生效；`verified` 由"相对正常 + 人工抽检通过"发放 |
| 三 | 用票 13 的标注集验证 | 报**误杀率（ok 被判异常）**与**漏杀率（坏帧被判正常）**；两者都写进票 13 结论，阈值随之修订 |

### 5. 接口（落在 `measure/src/measure/quality.py`，纯函数、可单测）

```python
@dataclass(frozen=True)
class FrameStats:          # 一帧的客观统计量
    lapvar: float
    p99: float
    overexposed_fraction: float

@dataclass(frozen=True)
class StationBaseline:     # 同站位同档的近窗基线（中位数 + MAD）
    n: int
    lapvar_median: float
    lapvar_mad: float
    p99_median: float
    p99_mad: float

def frame_stats(gray) -> FrameStats: ...
def relative_verdict(now: FrameStats, base: StationBaseline | None, *,
                     abs_p99_floor: float = 0.12) -> tuple[str, list[str]]: ...
    # 返回 ("ok" | "low_confidence" | "reject", [原因标记])
```

判定规则（初稿，参数待样本定）：

- **reject（绝对兜底）**：`p99 < abs_p99_floor`（近黑）或过曝占比 > 绝对上限；
- **low_confidence（相对异常）**：`lapvar < median - 3.5 × MAD`（纹理塌了，先扣镜头污/失焦），
  或 `|p99 - median| > 4 × MAD`（照度漂到本点位没见过的地方）；
- **ok**：其余；
- `base is None` 或 `base.n < 10` ⇒ 返回 `low_confidence` + `baseline_missing`
  （**不是 ok**：宁可不发 verified）。

`frame_quality()` 保留现在的绝对签名（现有调用方与测试不破），相对判据走新函数，
装配侧两段调用。

## 需要什么样本

完全沿用票 13 的抽样设计（L1 跨轮次 / L2 跨天 / L3 跨生长阶段 / L4 跨站位，约 200 帧
+ 加湿期/灯未亮/预览流/失焦四类坏帧对照各 ≥10 帧，每格独立标注不混池）。**相对法对
L3（跨生长阶段）尤其敏感**：它正是"绝对阈值为什么不行"的证据来源，样本量要够。
