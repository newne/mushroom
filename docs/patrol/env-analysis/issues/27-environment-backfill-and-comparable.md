# 27. 环境回填与逐批「可对照」判定

Status: ready-for-agent
归属：后端
依据：会话决定 D3；前置 = 立即动作 A2 的只读盘点
依赖：A2（`min(ts)` 盘点）

## 1. 交付物

1. 按盘点结果把环境数据**回填到可回溯的最早**（优先 611）
2. 每个批次标 `comparable=true|false`（缺段、断档超阈值 ⇒ false）
3. 产出**逐批覆盖天数与缺口清单**

## 2. 验收（缺一条不算过）

- [ ] 回填后每批有明确的起止与覆盖天数
- [ ] `comparable=false` 的批次**不参与**同期对照
- [ ] **绝不**用邻近批次或插值顶替
- [ ] 缺口清单可复算

## 3. 不做什么

- 不改原始分钟序列的权威（TDengine 仍是原始序列的权威）
- 不做跨库房的补全猜测
