# 蘑菇种植智能调控系统 - 项目结构

## 项目概述

本项目是一个基于 AI 的蘑菇种植环境智能调控系统，集成图像编码、环境监控、决策分析、API 服务与运维脚本。目录已经按“业务代码 / 文档 / 测试 / 运行产物”重新收敛，以下结构反映当前代码主干。

## 核心模块说明

### 1. 决策分析模块 (src/decision_analysis/)
负责基于历史数据和 CLIP 图像匹配生成环境调控决策。

**主要组件：**
- DecisionAnalyzer: 决策分析主控制器
- DataExtractor: 从数据库提取相关数据
- CLIPMatcher: 使用 CLIP 查找相似历史案例
- TemplateRenderer: 渲染决策提示模板
- LLMClient: 调用 LLM 生成决策
- OutputHandler: 验证和格式化输出

### 2. 视觉模块 (src/vision/)
负责图像识别、质量推理、批量处理与环境状态评估。

**主要组件：**
- clip_inference.py: CLIP 推理核心
- clip_inference_scheduler.py: 图像处理调度入口
- mushroom_image_encoder.py: 多模态编码器
- get_env_status.py: 环境状态获取

### 3. 调度系统 (src/scheduling/)
负责定时任务调度和执行。

**主要组件：**
- __main__.py: `python -m scheduling` 包入口
- core/scheduler.py: 调度器核心实现
- tasks/: 调度任务注册层

### 4. 工具模块 (src/utils/)
提供各种工具函数和服务。

**主要组件：**
- 数据库操作
- MinIO 对象存储
- 图像处理
- 数据可视化
- 设定点监控

## 文档与运行产物约定

- `docs/` 只保留业务、技术、算法三层文档索引
- `logs/`、`output/`、`.archive/`、`.pytest_cache/`、`.trae/` 视为运行或工具产物，不应作为长期源码结构的一部分
- 一次性验证脚本应优先迁移到 `tests/` 下的断言式测试，过期脚本应直接清理

## 数据流程

```
1. 图像采集 → MinIO 存储
2. CLIP 推理 → 图像特征提取 → 数据库存储
3. 环境数据采集 → 数据库存储
4. 决策分析：
   - 提取当前环境数据
   - CLIP 匹配相似历史案例
   - 渲染决策提示
   - LLM 生成决策建议
   - 验证和格式化输出
5. 设备控制 → 执行调控决策
```

## 日志系统

日志文件位于 `src/Logs/` 目录，按级别分类：
- critical.log: 严重错误
- error.log: 错误信息
- warning.log: 警告信息
- info.log: 一般信息
- debug.log: 调试信息
