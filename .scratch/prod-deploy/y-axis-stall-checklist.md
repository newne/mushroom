# Y 轴"运动被提前终止"现场排查清单

日期：2026-09-13 · 目标机 `10.77.77.39` · 控制器 `192.168.1.239:8088`

## 现象（一句话）

Y 轴做**长距离快速移动**时，控制器**偶尔自己提前终止**这次运动，然后照常报"已停"、
**不报任何错误码**。相机可能因此停在错位置——**已被到位校验拦住**，但根因未除。

## 已知的事实（省得重复测）

| 事实 | 证据 |
| --- | --- |
| 异常段的**耗时异常短** | 0.73 s（正常 3.3 s）；0.23 s（正常 30.4 s） |
| **与速度无关** | 150 / 90 / 50 mm/s 三档异常率相近 |
| **不是机械卡阻** | 10 mm/s 走完 0→4442 全程、两个方向，零异常（250 mm 步长逐格验证） |
| **不是丢步** | 限位基准法：拉长测量腿 2000 mm 后，触限耗时与基准差 ≤1.6 ms |
| **不是软件静默丢帧** | `wait_stop` 的提前返回已修（见 ADR/commit `a84d102`），修后成功段偏差 0.000 mm |
| 修复后整轮 | **59/60 成功**，唯一失败偏差 5.0 mm（此前 300–4400 mm） |

⇒ 剩下的是一个**硬件/电气**问题：控制器或驱动器在特定条件下中断了运动。

## 排查步骤（按性价比排序，前 3 步不需要工具）

### 步骤 1 · 听诊（5 分钟，最省事）

在**有人看护**下跑长程快速移动，听 Y 轴：

```bash
cd /opt/mushroom-patrol
PYTHONPATH=src FMC4030_LIB_PATH=lib/libFMC4030_2009_1.so \
  timeout -s KILL 600 venv/bin/python -X utf8 -u speed-ab.py --long 4 --short 4
```

⚠️ `timeout` 必须带 **`-s KILL`**：厂商 SDK 调用可能永久阻塞，SIGTERM 杀不掉
（实测卡在信号处理里 20 分钟没死，滑块停在 Y=5）。

**要听/看什么**：

| 观察 | 指向 |
| --- | --- |
| 皮带打滑的"啪"声、异响 | 机械：皮带张力 / 联轴器 |
| 走到某一段开始发闷、变慢 | 拖链阻力沿行程累积 |
| 完全没声音且没动 | 驱动器没收到脉冲（信号/使能） |
| 正常声音但中途停 | 驱动器保护（过流/过压/过热）动作 |

### 步骤 2 · 断电盘车（10 分钟，判断机械阻力）

**断电后**用手推滑块走完 Y 全行程：

- 阻力**均匀** ⇒ 机械没问题，重点查电气
- 某一段**明显变紧** ⇒ 拖链/导轨/皮带在该处有问题（记录位置区间）

### 步骤 3 · 驱动器电流设定（需厂商手册或现场记录）

`FMDD50D40NOM` 驱动器**无手册**（gap-list 已记）。要拿到/确认：

1. 当前**电流设定值**（拨码或参数）
2. 该设定对应的**额定/峰值电流**与电机铭牌是否匹配
3. 有没有**过流/过压/欠压报警记录**（驱动器面板或控制器日志）

**决定性实验**：把电流**调大一档**，复跑 `speed-ab.py`。

- 异常消失 ⇒ **确认是电流不足**，按新档位整定并记录
- 异常照旧 ⇒ 排除电流，转步骤 4

### 步骤 4 · 供电与接地（需万用表）

- 驱动器**供电电压**在长程加速时是否明显跌落（示波/万用表最小值档）
- 电源功率余量是否够（长程持续高电流 vs 短程脉冲式）
- 接地与屏蔽（脉冲信号受干扰会表现为"指令丢失"）

### 步骤 5 · 控制器侧

- `Get_Device_Para` 的 `div/lead` 是否被改过（应为 `100000/95`）
- 控制器有无"运行中保护"类设置项（说明书 §三.4 参数页）
- 固件 2015 + 库 20240920 是已知组合；如需升级**先问厂商**

## 判定与后续

| 结果 | 处置 |
| --- | --- |
| 电流调大后正常 | 记录新档位；`speed-ab.py` 复跑确认；M1 可继续观察 |
| 机械阻力不均 | 修机械（皮带张力/拖链），修后复跑 |
| 都正常但仍偶发 | 按"控制器自发终止"记入风险，**M1 保持有人值守**；到位校验已能拦住错位拍照 |

**无论哪种结果，两件事不要动**：

1. **不要**为了消除报警而关闭监视/保护（那是拿机构换安静）
2. **不要**为提高通过率而放宽容差（5 mm 那次是真偏差；放宽会放过真故障）
