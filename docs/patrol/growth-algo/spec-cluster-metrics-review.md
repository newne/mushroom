## 0. 一句话结论

spec 的主交付本来就是"簇级像素趋势"，但当前测量链有三套口径混在一起：

- **区域指标**（无基线）：`cluster_h_px` / `cluster_w_px` / `area_px` / `eq_diameter_px`；
- **基线高度**（有袋顶基线）：`H_profile = b(x) − t(x)`；
- **相邻帧差**：`delta`（探索链路的变更量）。

建议：**以"每帧、每袋的 `H_profile`"为主指标，区域指标为辅助，`delta` 降为 QA**；
单菌杆长度从本期 spec 的活跃字段中移除（保留历史代码与标记）；
分割以 **YOLO-seg 为主、无模型包络为兜底**；基线以**模板折线 + 每帧验证**为主，
图像自带袋沿为备选。验证用 100–150 帧人工标注，先证伪再谈精度。

## 1. 现状：三套口径各自量的是什么

### 1.1 区域指标（已实现，无基线）

`measure/baseline.py::BlobMetrics` 已产出：

| 字段 | 定义 | 主要污染源 |
| --- | --- | --- |
| `area_px` | 区域面积 | 阈值、孔洞、袋/塑料混入 |
| `bbox_px` | 外接框 | 同上 |
| `cluster_w_px` | 最宽行跨度 | 袋宽、相邻簇粘连 |
| `cluster_h_px` | 区域上下边界差 | **下边界与袋合并**、遮挡 |
| `eq_diameter_px` | `2√(A/π)` | 面积误差 |
| `widest_row_frac` | 最宽行相对高度 | 形状/阶段 |
| `split_ok` | 拆分是否可靠 | 粘连 |

`measure/estimate.py` 把它们聚合成 `ClusterEstimate`，`measure/record.py` 写
`mean_cluster_w_mm` / `mean_cluster_h_mm` / `mean_area_mm2` / `mean_projected_d_mm`。
注意：平视单档下的 `mean_cluster_h_mm` 是**未做 cosθ 补偿的竖直投影跨度**，带
`height_uncorrected` 标记（`measure/contract.py`），不是菌杆长度；这一语义必须保留。

- `cluster_h_px` 的**下边界**通常切在袋口/袋面，袋的可见高度会原样进入；
- `cluster_w_px` 的最宽行往往是**袋宽**，不是菌簇宽；
- 所以这两个量在"袋与簇没分开"时，量的是"袋 + 簇"，不是菌簇。

### 1.2 基线高度（spec §4.1，未实现）

```
H_profile = (1/|V|) Σ_{x∈V} [ b(x) − t(x) ]
```

- `b(x)` = 袋顶折线在该列的 y；`t(x)` = 簇顶包络；
- 物理含义是"袋口以上多高"，不是菌杆长度，也不是整簇外接框高度；
- 优点：**下边界不依赖簇掩码**（下边界是袋顶，不是簇的下缘），避开了 1.1 的最大污染源；
- 代价：需要基线；基线被簇遮挡时需要 §4.3 的两级可用性（插值/缺测）。

**这是本文建议的主指标**：它与"袋"这个稳定参照绑定，跨帧可比，且不依赖
"簇的下边界"这种不可靠的东西。

### 1.3 相邻帧差（探索链路，已跑）

`delta = median_x [t_A − (t_B(x−dx) + dy)]`：

- 不需要基线，适合先看"有没有动"；
- 但它是**变更量**，不是每帧量；不能跨锚点比较，也不能替代 `H_profile`；
- 建议降级为 **QA/一致性检查**：`H_B − H_A` 应与 `delta_AB` 在容差内一致；
  不一致就说明基线或分割有问题。

### 1.4 单菌杆长度（历史链路，不在本期）

`measure/estimate.py::estimate_stipe_length`、`StipeEstimate`、`p10_len/p90_len`
仍在代码里，但 spec 已把单杆测量移出本期；单档平视下 `mean_len_mm` 恒 NULL +
`no_angle_profile`。**本次修订建议把它们标为 legacy，不再出现在活跃字段/页面**。

## 2. 每帧菌簇能测什么

按"参照物"分三层，允许逐级降级：

```
Level 0  锚点级（整片前排菌簇，不做袋归属）
          t(x), 宽度, 面积, 等效径, 覆盖率
Level 1  袋级（一袋一簇，需归属 + 基线）
          H_profile, H_p50, H_p90, 相对高度, 宽度/面积
Level 2  帽级（仅帽期，辅助）
          cap_count, cap_area_fraction, cap_diameter_px（不做 mm）
Level 3  杆级（本期不做）
```

| 指标 | 定义 | 需要 | 能回答 | 不能回答 |
| --- | --- | --- | --- | --- |
| `H_profile` | `mean(b−t)` over V | 袋顶基线 + t(x) | 袋口以上平均高度 | 单株/单杆长度 |
| `H_p50` | `median(b−t)` | 同上 | 稳健高度 | 同上 |
| `H_p90` | `quantile(b−t, 0.9)` | 同上 | 最高那批结构 | 同上 |
| `cluster_width_px` | 簇掩码最宽行 | 簇掩码（去袋） | 横向铺开程度 | 菌盖直径 |
| `area_px` | 簇掩码面积 | 簇掩码 | 体量/覆盖 | 绝对尺寸 |
| `eq_diameter_px` | `2√(A/π)` | 同上 | 体量的单值摘要 | 盖径 |
| `rel_height` | `H_profile / ref_px` | 袋宽/袋高 | 跨锚点粗略可比 | mm |
| `rel_width` | `cluster_width / ref_px` | 同上 | 同上 | mm |
| `coverage` | 掩码/ROI 或有效列/列数 | 掩码/包络 | 这次量测有多少支撑 | 精度 |
| `cap_count` | 帽实例数 | 帽模型 | 帽期结构 | 朵数（遮挡） |

**关键区别**：`cluster_h_px`（外接框高度）不等于 `H_profile`（袋口以上高度）。
前者把袋的可见高度算进去，后者不会；两者应同时报，但不能互相替代。

## 3. 方法评估

### 3.1 分割

| 方法 | 产出 | 优点 | 失效 | 成本/标注 | 适用 |
| --- | --- | --- | --- | --- | --- |
| H1 亮实体 + 底部连通（探索） | t(x)、整片掩码 | 无模型、抗雾/亮弧、0.3–0.5 s | 不拆袋、不拆簇、覆盖率会变（S202 12%） | 0 | 兜底 / t(x) |
| H2 Otsu/HSV + 距离变换 + 种子拆分（`baseline.py`） | 区域实例 | 无模型、有实例、快 | 袋簇合并、整屏一块（S306 52%）、光照敏感 | 0 | 无模型基线 |
| H3 YOLO26s-seg（计划 P2） | bag/cluster/cap 实例掩码 | 语义/实例、可去袋、可关联 | 细杆/小帽漏检、需标注、CPU 成本 | 500–800 帧 | **主运行** |
| H4 SAM 2.1 / DINOv2 线性头 | 高质量掩码/语义 | 少样本、边界好 | 需提示/训练、CPU 慢 | 离线 | 标注/蒸馏/难帧 |
| H5 模板 + ECC | ROI/袋槽/袋顶 | 固定锚点极稳（墙带位移 ~1 px） | 换视角/换包失效 | 48 份模板 | ROI/基线 |

**建议**：H3 做袋/簇/帽实例；H1 做 t(x) 的兜底与 QA；H2 保留为无模型对照；
H4 只离线（标注、难帧、蒸馏），不进每帧运行时。

### 3.2 基线

| 方法 | 做法 | 优点 | 风险 |
| --- | --- | --- | --- |
| B1 模板折线 + ECC | 参考帧人工袋顶线，按平移映射 | 稳定、可审计 | 换视角/换包失效；模板人工量 |
| B2 图像自带袋沿 | YOLO bag 掩码上缘 / 边缘线 | 每帧自适应 | 袋沿被簇遮挡；袋相似易混 |
| B3 袋宽归一化 | 只做尺度，不做高度基线 | 无基线也能跨锚点粗比 | 分母 CV 0.249（spec §4.6）；不是高度 |
| B4 人工 | 标注 | 评估真值 | 不能量产 |

**建议**：B1 为主（与 spec §4.3 的两级可用性一致）；B2 作为换视角/模板缺失的备选；
B3 只用于相对指标，且必须同时报 `ref_px` 与袋宽 CV；**没有基线就不出 `H_profile`**，
但 Level 0 的宽度/面积仍可出。

### 3.3 归属（一袋一簇）

| 方法 | 做法 | 适用 |
| --- | --- | --- |
| A1 模板槽位 | 固定 `bag_slots`，按 ECC 映射 | 固定锚点，主力 |
| A2 几何一对一 | bag/cluster 框、底边接触、横向重叠、最近邻 | 模型实例可用时 |
| A3 学习归属 | 目前不做 | 数据足够后再议 |

**规则**：合并多袋 ⇒ `association_ambiguous`，**不强行分摊**；此时降级到 Level 0，
不产袋级 `H_profile`，但锚点级宽度/面积仍可出。

## 4. 建议的每帧量测协议

```text
每帧：
  1. L0 质量门（复用 quality；灯未亮/过曝/模糊 → 整帧不可用）
  2. L1 模板 + ECC → ROI / 袋槽 / 袋顶折线 b(x)
  3. L2 YOLO-seg → bag / cluster / cap 实例
     （失败或低置信 → H1 亮实体兜底，标 fallback）
  4. L3 归属：一袋一簇；合并/歧义 → Level 0
  5. L4 量测：
       t(x) = 簇掩码上缘（亚像素）
       V    = 列连续 + 向下连通到 b(x)（容差 reach_tol_px）
       H_profile = mean(b−t) over V
       H_p50 / H_p90 / raw_top = 分位数
       width / area / eq_diameter（簇掩码，去袋）
       rel_* = 上述 / ref_px（袋宽，报 CV）
  6. L5 有效性与证据：
       baseline_valid / association_valid / measurement_valid
       valid_ratio / coverage / quality flags / 版本四元组
```

**逐级降级**：

- 基线不可用 ⇒ `H_profile` NULL；宽度/面积仍出（Level 0/1 的形态度量）；
- 归属歧义 ⇒ 袋级指标 NULL；锚点级仍出；
- 簇掩码缺失 ⇒ 整帧 `no_detection`，不写 0；
- 帽模型不可用 ⇒ 帽级 NULL，不阻塞簇级。

**与 delta 的关系**：

```
一致性检查： | (H_B − H_A) − delta_AB | ≤ tol
```

`tol` 由静态重复对的噪声底定（建议先按 2–3 px）。不一致 ⇒ 标记
`baseline_or_mask_inconsistent`，该 pair 不用于校准，但保留证据。

## 5. 评估实验（先证伪）

### 5.1 数据

- 100–150 帧，按层 × 光照 × 阶段 × 事件分层；
- 人工标注：bag 掩码 + 袋顶折线、cluster 掩码 + 顶部边界、袋宽；
- 帽期另标 30–50 帧帽掩码；**不标菌杆**；
- 静态重复对 10–20 对（同站位分钟级），用于噪声底；
- 锁定测试集按 `round_id` 分组，禁止相邻锚点泄漏（spec G8）。

### 5.2 对照方法与指标

| 方法 | t(x) | 基线 | 归属 | 宽度/面积 |
| --- | --- | --- | --- | --- |
| H1 亮实体 | ✓ | — | — | 粗 |
| H2 Otsu/DT | 粗 | — | 部分 | ✓ |
| H3 YOLO-seg | ✓ | bag 上缘 | ✓ | ✓ |
| H5 模板 | — | ✓ | ✓ | — |
| H3+H5（建议） | ✓ | ✓ | ✓ | ✓ |

指标：

- `t(x)` 与人工顶部折线的 MAE（px）；
- `b(x)` 与人工袋顶折线的 MAE（px）；
- `H_profile` 与人工 `mean(b−t)` 的 MAE（px）；
- 宽度/面积的相对误差（只在不粘连的袋上）；
- 归属正确率（前排一袋一簇）；
- 同图重复（两次推理/阈值抖动）的重复性；
- 静态重复对的假增长（px）；
- 延迟 p50/p95（目标 4 核）。

### 5.3 门槛（建议，需冻结）

| 指标 | 门槛 |
| --- | --- |
| `H_profile` MAE | ≤5 px |
| `b(x)` MAE | ≤4 px |
| `t(x)` MAE | ≤4 px |
| 宽度相对误差 | ≤10%（不粘连袋） |
| 归属正确率 | ≥95%（前排） |
| 静态重复假增长 | ≤1 px |
| 延迟 p95 | ≤3.75 s/帧 |
| 分层回归 | 任何一层不差于基线 10% |

### 5.4 关键消融

- `H_profile` vs `cluster_h_px`：同一批帧上比，验证"袋底下边界污染"假设；
- H1 vs H3 的 `t(x)`：模型是否真的改善顶部边界，还是只改善掩码 IoU；
- B1 vs B2 基线：模板与图像自带袋沿的偏差；
- 归属成功 vs 降级 Level 0 的比例；
- 阈值/置信度敏感性。

## 6. spec 修订建议（delta 表）

| spec 项 | 现状 | 建议 | 理由 |
| --- | --- | --- | --- |
| 主指标 | `H_profile`（§4.1） | **保留并明确为每帧主指标**；加 `H_p50`/`H_p90` | 与袋口绑定，避开簇下边界污染 |
| 区域指标 | 辅助（§4.2） | 保留为辅助；明确"去袋后的簇掩码" | 现有 `cluster_h/w` 会被袋污染 |
| 相对尺寸 | §4.6 | 保留；强制报 `ref_px` 与袋宽 CV | 分母方差是主导误差 |
| 相邻帧 delta | 探索 | **降为 QA/一致性检查**，不做主曲线 | 是变更量，不是每帧量 |
| 单杆 | 历史链路 | **标 legacy**；`mean_len_mm`/`p10/p90_len` 不进活跃字段 | 单档平视不可测；spec 已移出 |
| 菌帽 | 辅助支线 | 保留；只做 px 与计数，不做 mm | 角度档限制 |
| 输出粒度 | 逐袋/锚点 | 明确 Level 0/1/2 与逐级降级 | 归属失败仍能出锚点级趋势 |
| 有效性 | §4.3/§4.4 | 每个指标独立 validity；NULL 不写 0 | 避免"一个失败拖垮整行" |
| 评估 | §9 | 增加"每帧量测方法"对照实验（本文 §5） | 现在只有链路级验收 |

**不建议现在改的**：mm 解锁、帽径绝对尺寸、单株归属、跨层绝对可比。
这些仍受角度档/标定/数据窗口约束。

## 7. 风险与未决

- **Q1 基线遮挡**：簇越长越挡袋口；§4.3 的两级可用性是否足够，需要实测。
- **Q2 袋簇分离**：YOLO 若把袋与簇合并，宽度/面积仍被污染；需要 `association_ambiguous` 降级。
- **Q3 `H_profile` vs `cluster_h` 的相关性**：若两者高度相关，是否可以先用无基线的 `cluster_h` 过渡？
  —— 这正是 §5.4 的第一个消融，**先别下结论**。
- **Q4 前端**：Level 0/1 的 NULL 语义要在页面上分开显示，不能把"没基线"画成 0。
- **Q5 版本/分段**：`H_profile` 换基线/换模型要分段，不能与旧值连成一条。
- **Q6 成本**：YOLO + 模板 + 人工复核的总成本；DINO 只离线。
