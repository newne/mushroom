## 3. 显示位置与文案（页面）

1. **一期交付量位置**（票 14 定的"排在最前"不改）：菌簇平均长度、平均直径两格；
2. 每格 = **值 + 量纲 + 态标签**，形如 `24.3 mm 估算（菌包标尺）`；态标签用**中性色**（不用红，
   估算不是错误，只是未经标定）；
3. **估算值必须与"已验证/实测"在视觉上分开**：估算格用弱底 + 标签；**同一张卡里的"已验证"计数不含估算行**；
4. 长势曲线：**估算值不上主线**（票 11/16 的规矩：异量不进一条线）；若要画，单独一条虚线 + 图例写明"估算"；
5. 详情区/对比卡同理，一句话：**任何出现这两个数的地方都带态标签**。

## 4. 三类计数怎么分开（要一句口径）

建议每张测量卡底部固定三个计数，数字全部来自数据、**不写死**：

```
估算 12 · 不可测 3 · 不可用 5（本区间 20 行）
```

- **按列 × 行**判（"按列判不按行判"是既有规矩：一帧里菌簇量可测、盖径不可测）；
- **估算计数绝不并入"已验证"**；三个数字相加 = 该区间相关行数（对不上就说明有第 4 类没命名）；
- 待确认：`unreliable`（票 18 §1.2 的远排/低置信）算"不可用"还是单列第 4 类？**我倾向算"不可用"**
  （与 `no_light` 同级，票 18 自己也这么写），但要你或环境官一句确认。

## 5. **不确定度：Chief 2026-10-14 裁定 —— 不新增列，用现成的分位数区间**

用户口径要求"估算值必须带不确定度"，但**全库没有** SD / 置信区间列。裁定：
**一期就用现成的 `p10_len`–`p90_len` + `n`**，措辞写「**P10–P90**」，**绝不写 `±`**——
分位数区间与标准差是两种东西，写成 `±` 就是撒谎。

**三条硬约束（都在页面上，都要有断言）**：

1. **`n < 5` 不显示区间**，只写「**样本不足（n=X）**」。
   阈值写成页面常量 `UNC_MIN_N = 5`（**可配置**）。**理由**：2 个点也能摆出一个"区间"，
   那是**假精确**——现场会拿它当"波动范围"用，比不给更坏。取 5 的依据：一期菌簇量按帧算，
   同一站位同一天的可用帧本来就个位数，`n<5` 时 p10/p90 几乎就是 min/max。
2. **`no_scale` / `unreliable` 的行不显示区间**——无值就是无值，**不拿区间兜**
   （既没标尺又给区间，等于把"不可测"包装成有量）。
3. **将来要 `±SD`/置信区间**：**先有列**（测量师新开列并写明是哪种区间：SD / CI / 其它），
   页面才显示；在那之前**不发明、不估算、不换算**。

被判分位数量在 `estimated_fields` 里时，区间照同样规则显示，并且**整格带「估算（标尺来源）」**——
区间不能把估算洗成"已验证"。

**另有一处不由我定名**：一期两格到底是哪两列（`mean_cluster_w_mm` / `mean_cluster_h_mm` 还是
别的组合）**由测量师确认**（Chief 2026-10-14 已指派他去问），我不替它定名——名字错了，
显示得再清楚也是错的。

## 6. 可扫描断言（实现时必须逐条有）

1. **估算带标签与来源**：估算值出现处必含「估算」+ 标尺来源中文名；量纲跟数字走；
2. **估算不进"已验证"语境**（负向）：同一卡的"已验证"计数里不含估算行；断言"估算值不出现在 `verified` 计数"；
3. **缺标尺 ⇒ 不可测**：`no_scale` ⇒ 文案「不可测（无标尺）」，且该格**不出现任何数字**（尤其不许 0）；
4. **`no_angle_profile` 不再是这两列的默认文案**（负向钉子）：有标尺的估算行**不许**出现「无角度档」；
   只有在确实没有角度档（且无标尺）时才用它；
5. **不可用优先**：帧带 `no_light`/`no_detection` 时，文案是「不可用（原因）」，**不是**"不可测"；
6. **三类计数分开**：三个计数都来自数据、相加 = 行数；估算数 ≠ 已验证数（造一条估算行就必须体现）；
7. **契约三件套**：新列进 `CONTRACT` / `PAGE_CONSUMES`；**可 NULL 的列不进 `required`**；
8. **区间的三条钉子**（§5 的裁定）：
   - `p10_len`/`p90_len` 在场且 **`n ≥ 5`** ⇒ 文案含「**P10–P90**」且**不含 `±`**；
   - **`n < 5`** ⇒ 写「**样本不足（n=X）**」，且**不出现任何区间数字**（防"2 个点摆区间"的假精确）；
   - `no_scale` / `unreliable` 的行 ⇒ **不显示区间**（走不可测/不可用文案，不拿区间兜）；
   - 两个分位列不在场 ⇒ **不出现 `±`/区间数字**（防自造）。
