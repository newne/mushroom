# 02. 历史 tab：小倍数矩阵（12 列 × 4 层物理布局）

Status: ready-for-agent
归属：前端
依据：docs/patrol/growth-timeline/spec.md
依赖：01

## 交付物

在历史 tab 新增「时序总览」卡：**48 格按 layer/col 排，与平面图物理布局一致**；每格一张 sparkline。

- x = 本批时间轴（真实时间）；y = 覆盖/质量
- 状态色：灰 = 该轮无数据、蓝 = 有帧、绿 = 上升、红 = 下降/异常
- hover 显示站位、轮次时间、帧数

## 验收（缺一条不算过）

- [ ] 格数 = 站位格数（按 `grid.cols × grid.layers` 算，**不是死写 48**）
- [ ] 布局与平面图**同一套 col/layer 顺序**，现场一眼能对上位置
- [ ] 缺口**断开画**；把断开改成连线 ⇒ 断言变红
- [ ] `null` **不画成 0**；把 null 当 0 ⇒ 断言变红
- [ ] **零新前端依赖**（手写内联 SVG）
- [ ] 无头回归新增断言全绿，且失败清单与基线**逐条同名**

## 不做什么

- 不做单节点放大（票 03）
- 不做分位数带（票 04）
- 不改既有「生长曲线」卡
