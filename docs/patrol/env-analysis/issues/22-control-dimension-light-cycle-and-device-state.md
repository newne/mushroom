# 22. 调控维落库：补光循环制度 + 设备运行状态

Status: ready-for-agent
归属：后端
依据：`docs/patrol/env-baseline/spec.md`（调控维）；会话决定 D13
依赖：立即动作 A2（只读盘点：确认环境表是否已有补光列）

## 1. 交付物

1. 补光**循环制度**：开/关的分钟级与秒级设定、分路开关、白/蓝选择、模式
2. **实际占空比**由运行状态派生，与设定**并排**，用来分辨「设了没开」
3. 空调、加湿、冷风机的**模式与运行状态**并入同一维
4. **改写**既有 lamp-hours 票的交付物：累计点亮分钟从「主口径」降为「派生对照」

## 2. 验收（缺一条不算过）

- [ ] 可按**生长阶段**切片看到该阶段的补光制度
- [ ] 设定 vs 实际可对照，且两者分列不混
- [ ] DDL 变更**经评审**后落地（既有票明说不动 DDL）
- [ ] 环境模式里「补光」卡片的数据源改为制度维

## 3. 不做什么

- 不做**照度**（无数据源；保留列但不显示成 0）
- 不改历史列语义、不删旧字段
