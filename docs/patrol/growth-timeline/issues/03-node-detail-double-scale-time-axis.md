# 03. 单节点放大：双刻度时间轴 + 环境带叠加

Status: ready-for-agent
归属：前端
依据：docs/patrol/growth-timeline/spec.md
依赖：01；**与票 02 同文件（web/console/index.html）⇒ 必须排在 02 之后**

## 交付物

点总览里任一格 ⇒ 进入该节点的放大视图：

1. **双刻度时间轴**：真实时间（主）+ 生长第 N 天（次）
2. **环境带**叠加：温度 / 湿度 / CO₂，以及**光照循环制度**（`OnMSet`/`OffMSet` 切段，不是累计分钟）
3. **巡检覆盖条**：该站位每轮有没有帧
4. 缺测段**断开**，鼠标悬停给出该点信息

## 验收（缺一条不算过）

- [ ] x 轴**按真实时间戳定位**；把 x 换成数组下标（等距）⇒ 断言变红
- [ ] 生长天数刻度与真实时间刻度**同一条轴**、对齐正确
- [ ] 光照按**循环制度切段**显示，**不得**用 `Running` 积分冒充点亮时长（ADR-0025/用户口径）
- [ ] 缺测段断开；两点之间若无中间轮次，**不许直连**
- [ ] 零新依赖

## 不做什么

- 不做跨批同期叠加（那是 env-analysis 票 23）
- 不做按生长天数的分布（票 24）
