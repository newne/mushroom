# 06. 时间刷选与筛选交互

Status: ready-for-agent
归属：前端
依据：[docs/patrol/growth-timeline/spec.md](spec.md)
依赖：05（同文件）

## 交付物

1. **时间刷选**：拖拽选一段时间 ⇒ 总览、放大视图、分位数带**同步聚焦**
2. **筛选**：按层 / 按列 / 按"有没有数据"筛（沿用页面既有 `data-station-filter` 手法）

## 验收（缺一条不算过）

- [ ] 刷选后三处视图**同源同步**（不各算各的）
- [ ] 筛选后格数变化正确，且**不隐藏"被筛掉"的事实**（给出计数）
- [ ] 刷选到"没有数据"的区间时，三处一致显示空态，**不显示成 0**
- [ ] 零新前端依赖

## 不做什么

- 不做跨批对照（票 23）
- 不做导出
