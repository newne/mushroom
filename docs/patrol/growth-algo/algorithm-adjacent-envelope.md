# 相邻帧簇顶包络算法设计（探索稿）

Status: **draft / exploration**（不是 `ready-for-agent`，不是 `verified`，不接生产）

> 本文件是 [spec.md](spec.md) 之外的一条**探索链路**的详细设计：不训练模型、不建表、
> 不写 `measurements`，只回答"同一锚点相邻两帧之间，可观测的簇顶轮廓有没有上移、上移多少像素"。
> 它**不改变** spec 的任何裁定，也不替代 L1–L5。它要做的事是：在 P3-3/P3-4 的模型与基线
> 落地之前，先把"对齐 → 分割 → 量测 → 聚合"的可复算链路和**可证伪的诊断**跑通。
>
> 写于 2026-10-19。所有"实测"数字来自 `.scratch/growth-trend3/` 与
> `.scratch/growth-vis/`，可复跑；**它们只证明链路在跑，不证明长势结论**。

## 0. 结论边界（先划清楚，避免把探索量当结论）

**本链路能说的：**
- 在给定两帧、给定阈值族下，**可复算**出一个逐列顶包络差 `delta(x)` 及其分布；
- 当分割覆盖、形状相关、两半一致性都通过时，这个分布的**中位数**是"簇顶轮廓上移"的一个
  像素估计，而不是"蘑菇长了多少毫米"；
- 当这些诊断不通过时，链路**能说出为什么**（覆盖不足/形状不像/分布双峰/事件性下降），
  而不是硬给一个数。

**本链路不能说的：**
- 不能给 mm；不能给单株/单朵的增长；不能区分"新菇冒出"与"原有菇长高"；
- 不能把负的 `delta` 当"负增长"：它更可能是采收、换面、遮挡或结构变化（见 §11 的 S106 例）；
- 不能在**没有锁定测试集、没有人工对照**的情况下宣称"整体长势"。
  当前曲线只用于检查链路与暴露问题（§12）。

## 1. 可观测定义

固定站位、平视相机、菌包不动；菌簇从袋口向上长。画面里 **可观测的是菌簇的外轮廓**，
不是菌杆长度，也不是菌帽直径。因此在本文里：

- 输入：同一 `station_id` 的两帧 `A`（较早）、`B`（较晚），间隔 `Δt`；
- 分割：**与画面底部连通的亮实体**（§6），记为掩码 `M`；
- 量测：`M` 的**顶部包络** `t(x)`（每列第一个前景像素的 y，亚像素）；
- 输出：`delta(x) = t_A(x) − t_B_aligned(x)`，单位**原图像素**；`delta > 0` 表示 B 的轮廓更高；
- 聚合：对列取中位数 `median_x delta(x)`；对锚点再取中位数（§8）。

**术语纪律**（沿用 spec §4.4/§7）：文案写「簇顶轮廓抬升」「簇级形态变化」，
不写「平均菌杆长度」「同一蘑菇增长」。

## 2. 坐标系与符号约定

以 `A` 为参考帧，`B` 为移动帧：

```
phase_shift(A, B) -> (dy, dx, peak)      # 约定：A(y,x) ≈ B(y − dy, x − dx)
```

即把 `B` 对齐回 `A` 时：

```
t_B_aligned(x) = t_B(x − dx) + dy
delta(x)       = t_A(x) − t_B_aligned(x)
```

`dy > 0` 表示 B 的画面内容整体比 A **高**（图像坐标 y 更小）；`dy < 0` 表示 B 更低。
推导：`A(y) = B(y − dy)`，若 `dy=+5`，则 B 里同一结构在 `y−5` 行 ⇒ B 更靠上。
这个符号最容易搞反，`measure/tests/test_explore_growth_adjacent.py::test_phase_shift_sign`
用合成平移钉住了它。所有 `top` 在 `profile_frame` 里都加上了 ROI 的 `y0`，回到整帧坐标；
可视化在裁剪图上工作时再减回去，**两条轮廓同减一个常数，delta 不变**。

## 3. 数据流

```
frames (console GET, 只读)
   │
   ├─ L0 帧质量门（quality.frame_quality + ROI 平均亮度）
   │
   ├─ L1 对齐（静态墙带 FFT 相位相关；平移 + 亚像素）
   │
   ├─ L2 分割（1/2 降采样 → 亮实体 → 底部连通传播 → 上沿对比门）
   │        └─ 证据：mask / keep / edge_ok / env_coarse
   │
   ├─ L3 量测（全分辨率亚像素包络 → 逐列 delta → 分位数/两半/形状相关）
   │
   └─ L4 聚合（小时桶 → 锚点中位数；覆盖率与缺测一起报）
```

## 4. L0：帧质量门

复用 `measure.quality.frame_quality`（仓库里唯一一份判据），另加一条**ROI 平均亮度绝对下限**
`min_luma=40`。理由：灯没亮的轮次整帧近黑，`frame_quality` 的对比度类判据可能仍"通过"，
但包络没有意义。

**状态**：`frame_quality` / `too_dark` / `no_contrast` / `few_valid_columns`。
帧级计数器全部写进 `frames.csv`，不静默丢。

## 5. L1：对齐（只用静态墙带）

### 5.1 为什么不用整帧

整帧相位相关会被**正在长的菌簇**带偏。实测 S102 跨天帧：整帧相关给出 **~90 px** 的 dy，
足以触发 `view_changed` 把一对好数据整对拒掉；而同一对只用墙带（ROI 上方 5%–32% 行）
估出来是 **0.41 px**。菌簇是"会动的内容"，墙是"不动的参照"，对齐只能用后者。

### 5.2 实现

1. 取 `align_y0..align_y1`（默认 0.05–0.32）的整幅宽度；
2. 4× 盒降采样；遮掉左上角的角标时间戳（每帧文字不同）；
3. Hanning 窗 → `rfft2` → 归一化互功率谱 → `irfft2`；
4. 峰值位置 + 抛物线亚像素；
5. 乘回 4× 得整帧位移；峰值比 `peak` 作可靠性诊断；
6. `|dy|` 或 `|dx| > max_shift_px=40` ⇒ `view_changed`；`peak < min_align_peak=4` ⇒
   `align_unreliable`。

### 5.3 已知缺口

- 只修**平移**，不修缩放/旋转。若发生 Z 向 re-anchor，菌簇会按"离光心距离"成比例位移，
  平移对齐会把这部分算成抬升。**建议上生产前加一道墙带上下子带位移差**（见 §13 Q4）。
- 墙带被水汽/反光污染时，位移估计会退化；`peak` 只是弱诊断，不能当放行条件。

## 6. L2：分割（底部连通的亮实体）

### 6.1 定义

**不是语义分割**。本链路把"菌簇"定义为一个**与画面底部连通、亮度高于局部背景的实体**。
这一定义有三个直接后果，必须写出来：

1. 袋子、袋口塑料、菌柄会一起进入掩码——我们不区分器官，只要外轮廓；
2. **与底部不连通的亮区（背景亮弧、水汽、反光、另一袋）不算**——这正是本算法的抗噪机制；
3. 连通集合会随生长/遮挡变化（§13 Q1）——同一锚点不同帧的有效列集合可能不同；
4. **早期（原基/菌丝）阶段包络可能贴在袋口/塑料膜上，而不是菌帽上**——此时它测的是
   "亮实体的顶"，不是"菌帽顶"；早期曲线的平台不能直接读成"没长"。

### 6.2 阈值模型

在 1/2 降采样 ROI 上：

```
wall   = median(顶部 1/4 行)                 # 静态墙/背板亮度
span   = p99.5(ROI) − wall                   # 本帧动态范围
thr    = wall + k·span,   k = 0.45 (敏感性 0.35 / 0.55)
mask   = coarse > thr
```

为什么是**全局**阈值而不是逐列阈值：逐列分位差在"整屏晕影/水汽"帧上会被列内亮区拉偏，
把雾层当菌簇（实测 S102 跨天帧虚高 200+ px；S202 的雾团在可视化里是一整块红色亮区）。
全局阈值 + 底部连通，让"亮但不连通"的东西自然出局。

### 6.3 底部连通传播

```python
seed = mask[底部 10% 行].any(axis=0)
keep = zeros_like(mask)
for y in range(h-1, -1, -1):                  # 从底往上
    row   = mask[y] & dilate1d(seed, r=2)     # 横向容差 2 个粗像素（= 4 原图像素）
    keep[y] = row
    seed  = row
env = argmax(keep, axis=0) * 2                # 每列第一个连通行的 y
```

`dilate1d` 用布尔移位实现（无 scipy/opencv 依赖）。复杂度 `O(h·w)`，1/2 分辨率下传播
本身数十毫秒；**整帧**（解码 + 平滑 + 三档阈值 + 亚像素）实测 **0.3–0.5 s/帧**（单核）。

**它不是什么**：不是形态学开闭、不是洪水填充的精确连通分量。它只沿**竖直方向**传播，
横向容差 `r` 用于跨过细缝；因此"从底部斜着长出去"的结构可能被漏掉，这是已知近似。

### 6.4 上沿对比门 + 亚像素

对每个原图列，在粗包络 `±5 px` 内找"暗→亮"的中点：

```
below = mean(sm[t+3 : t+9])
above = mean(sm[t−9 : t−3])
level = (below + above)/2
edge  = below − above
```

- `edge ≥ edge_frac·span`（默认 0.12）才算有效列——雾层那种缓边界不算；
- 在 `t±5 px` 的 9 行窗口里找 `level` 的第一个上穿点，线性插值到亚像素；
- 找不到交点则回退到粗包络（并保留 `has_cross=False` 作诊断）。

### 6.5 分割的失败模式（可视化里能直接看到）

| 现象 | 后果 | 现有对策 | 缺口 |
| --- | --- | --- | --- |
| 亮墙/水汽与底部连通 | 包络贴到墙上 | `edge_frac` 对比门 | 雾很浓时会整列失效 |
| 左侧袋与主体不连通 | 该袋不参与量测 | 覆盖率门 | 有效集合随帧变化（Q1） |
| 袋口塑料反光成亮弧 | 包络上跳 | 底部连通 | 反光若连到底部会误判（Q5） |
| 采收后留下空隙 | 包络下跳 | 无（当前只报数） | 事件分类（Q3/Q6） |
| 菌簇被采后重新长 | 两段不同分布 | 无 | 必须分段，不能连成一条 |

## 7. L3：量测

### 7.1 逐列有效规则

一列进入统计，必须同时满足：

1. `t_A(x)` 有限（A 的包络存在且过上沿对比门）；
2. `t_B(x−dx)` 有限（**最近原始列**有效，不是 `np.interp` 跨空洞补出来的值）；
3. `delta(x)` 有限（`t_A − (t_B_aligned + dy)`）。

第 2 条是显式修过的 bug：`np.interp` 会把 B 的无效段跨过去线性补值，补出来的平滑弧线
会混进中位数（自检用例 `test_measure_delta_does_not_count_interpolated_gap` 钉住）。

### 7.2 统计量

```
delta_med   = median_x delta(x)
delta_p25/75 = 分位数（分布宽度；单峰时约等于测量噪声 + 真实异质性）
delta_left/right = 左右两半各自的中位数（空间一致性）
corr        = corr(t_A, t_B_aligned)（轮廓形状是否同形；<0.7 多半在追不同结构）
valid_ratio = 有效列 / ROI 列数
```

### 7.3 当前门限（**探索值，未冻结**）

| 门 | 值 | 作用 |
| --- | --- | --- |
| `min_valid_ratio` | 0.15 | 有效列太少 ⇒ `few_valid_columns` |
| `min_coverage_ratio` | 0.50 | 两帧有效列数之比 < 0.5 ⇒ `coverage_changed` |
| `max_luma_ratio_dev` | 0.25 | 曝光突变 ⇒ `exposure_changed` |
| `max_span_ratio_dev` | 0.60 | 对比度突变（水汽/照度）⇒ `contrast_changed` |
| `max_growth_px` | 150 | 单对位移超过 ⇒ `delta_outlier` |
| `max_half_gap_px` | 12（或 0.75·delta） | 两半差 ⇒ `halves_inconsistent` |
| `profile_corr` | **仅诊断，暂不硬门** | 见 §11 的 S106：corr=0.56、双峰，仍被当前门放过 |

### 7.4 不确定性

- **像素量化**：包络来自 1/2 粗网格 + 亚像素细化，单列量化约 0.5–2 px；中位数在 ~700 列上
  平均后远小于 1 px；
- **对齐**：墙带位移中位 0.65 px（3h）/0.98 px（日），p95 5.2/3.1 px；
- **阈值**：k 0.35/0.55 两档的 delta 差，3h 中位 −0.18 px、日尺度 4.9 px（在 41 px 上约 12%）；
- **空间异质性**：`p75−p25` 在干净对约 5 px、跨天对约 31 px、事件对约 157 px。
  这个宽度是"这一对可不可信"的第一手信号，比单个中位数更重要。

**没有**统计置信区间、没有重复测量方差分解、没有人工真值——这些是 §12 要做的事。

## 8. L4：聚合

- 时间桶：细粒度按轮次小时；日尺度按固定小时（本批用 15 点，12 点对 layer3/4 常 `too_dark`）。
- 锚点曲线：每个通过的 pair 把 `delta` 累加到该锚点的累计值；**缺测留平台，不插值**。
- 锚点中位数：每个小时桶取**在该桶有有效点的锚点**的中位数；没有有效点的锚点**不进分母**，
  否则零增长锚点会把中位数稀释（实测 12 锚点含两个 0 时，日末中位从 93.8 掉到 85.0）。
- 累计曲线是**下界**：只累加通过门限的对，被拒时段留平台；速率看单对中位数，不要拿累计
  当绝对长势。
- 不做单调化、不做平滑、不强制增长；负值原样保留，并应单独标成**事件**（§13 Q3）。

## 9. 状态与证据

每个 pair 输出一行，字段与状态码一一对应；`frames.csv` 记每帧的阈值/跨度/有效列数/告警。

```
ok | frame_quality | too_dark | no_contrast | few_valid_columns |
view_changed | align_unreliable | exposure_changed | contrast_changed |
coverage_changed | delta_outlier | halves_inconsistent
```

**证据链**：原图路径（由 `frames-dir` + ts + station 唯一确定）→ 帧级状态 → pair 级
`shift/dy/peak/valid_ratio/corr/halves` → 锚点累计 → 图中每个点。所有输出都是 CSV/PNG/SVG，
不写数据库。

## 11. 诊断可视化：每张图回答什么

工具：`measure/tools/viz_growth_diagnostics.py`。输出在 `.scratch/growth-vis/`，
`index.html` 可直接打开。当前样例：

| 图（`.scratch/growth-vis/`） | 这对数据 | 它说明了什么 | 它**没有**证明什么 |
| --- | --- | --- | --- |
| `pair_S102_2026-10-19_2026-10-19_1215.png` | 3h 相邻轮次 | delta=14.4 px，p25/p75=11.9/16.8，corr=0.987，分布单峰 | 这 14 px 是"真实生长"而非光照/姿态的残余 |
| `pair_S102_2026-10-18_2026-10-19_1515.png` | 跨天 | delta=93.5 px，p25/p75=72.1/103.6，corr=0.833，两半 87/99 | 跨天的 Z 向缩放没有被平移对齐吸收 |
| `pair_S202_2026-10-18_2026-10-19_1515.png` | 水汽/亮墙 | 顶部亮团（红）**不连通**、不进包络；有效列仅 12%，分布很宽 | 这类帧能给出可用的长势数（它应被 `few_valid_columns` 拒） |
| `pair_S106_2026-10-12_2026-10-13_1514.png` | 疑似采收/换面 | delta=−117 px，直方图**双峰**，corr=0.558，两半 −93/−164 | 这是"负增长"；它更可能是事件（Q3/Q6） |

每张 PNG 的六个面板：

1. **A 分割**：红=亮但不连通，绿=底部连通，黄=顶部包络；
2. **B 分割**：同一套颜色；
3. **双包络叠在 A 上**：红=A、绿=B 对齐；B 的无效列留空（不插值），并裁到菌簇包围盒；
4. **逐列 delta**：数据线 + p25/p50/p75 + 零线；底部绿色刻度=两帧都有效的列；
5. **delta 直方图**：看单峰/双峰/长尾；
6. **1:1 边界放大**：最高点附近的原始像素与亚像素包络，用来判断"边界贴的是菌帽还是雾"。

**读图方法**（先看哪三个数）：

1. **覆盖率**（绿色刻度是否连续）——不连续就别看中位数；
2. **直方图是否单峰**——双峰说明两个结构在打架（S106）；
3. **corr 与两半差**——形状不像/两半分家，说明追的不是同一片。

**必须补的真实数据测试**（spec §9.2 的三类，按本链路改写）：

1. **静态重复**：同站位分钟级手动抓拍对（spec G7）⇒ 真实噪声底；本链路目前的"3h 相邻"
   不是静止对，不能当噪声底。
2. **人工对照**：抽 30 对，人工在图上标"顶部边界确实上移/没动/下降"，与本链路的中位数

3. **事件对**：采收/换包/换面的已知事件，必须被判成 `drop/event`，不能进增长曲线。
4. **锁定测试集**：与 spec 同一套冻结纪律；当前所有数字都是开发集自检。

**当前明确未做**：mm 标定、单株对照、成熟期（帽期）样本、跨层可比性、Z 向缩放监控。

## 13. 已知混杂与未决问题（**不要把以下任一条当已解决**）

- **Q1 连通集合随生长变化**：S102 10-18 有效列 772，10-19 为 935。生长会让更多菇/袋连成
  一片，量测的"那片"本身在变。当前用"两帧交集 + 覆盖率门"缓解，但没有证明交集是稳定的。
- **Q2 中位数会掩盖空间异质性**：两半差、p75−p25 已经报出，但还没有"按袋/按排"的分解。
- **Q3 负 delta 的语义**：当前 `ok` 允许负值；S106 的 −117 px 会被写进曲线。需要把
  `growth / flat / drop / event` 分开，`drop` 只进事件日志，不进增长曲线。
- **Q4 Z 向缩放**：只修平移。若 re-anchor 或变焦，菌簇按离光心距离成比例位移；
  建议用墙带上下两条子带的位移差做监控（尚未实现）。
- **Q5 塑料反光/水滴**：底部连通能挡"半空亮弧"，但连到底部的反光仍会抬高包络；
  当前只能靠 `edge_frac` 与人工看图，未量化。
- **Q6 采收/新菇**：分段需要事件源（spec B4 未解）；当前只能标 `drop`，不能自动解释。
- **Q7 灯窗**：12 点对 layer3/4 常 `too_dark`；生产上应按帧亮度挑当天可用轮次，不写死钟点。
- **Q8 阈值敏感性**：日尺度 4.9 px（约 12%），在"可接受"与"太大"之间没有裁决；
  需要和人工对照的误差一起看。
- **Q9 覆盖率门的口径**：`min_valid_ratio=0.15` 是拍的；S202 的 0.12 被拒、S102 的 0.27 通过，
  但 0.2 附近的行为没有扫过。
- **Q10 没有真值**：本文所有"看起来合理"都不等于正确；§12 的对照与锁定测试集才是门槛。

## 14. 与 spec 的关系 / 下一步

- **不替代**：L1–L5 的语义分割、袋顶基线、一袋一簇、`H_profile` 仍是主交付；
  本链路的 `delta` **不是** `H_profile`，也不能写进 `measurements`。
- **可复用**：L1 的墙带对齐（spec P3-1 的"平移优先 + 稳定背景"）、L0 的质量门、
  §7.1 的"无效列不插值"、§8 的"缺测留平台"。
- **可喂给 P3-3/P3-4**：把本链路的 `valid_ratio / corr / halves / 覆盖率` 作为
  `usable` 门的候选证据；把"底部连通"作为无模型基线，用来对照模型分割的漏检/过检。
- **下一步（按优先级）**：
  1. 补静态重复对与人工对照（§12-1/2）；
  2. 加 `growth/flat/drop` 分类与 `corr` 硬门（Q3/Q9）；
