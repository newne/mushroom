## 3. 我需要的契约（写清楚，别让我猜）

### 3.1 菌簇长度/直径 + 不确定度（等测量侧 → analysis）

- **量**：菌簇**平均长度**与**平均直径**要落成哪两个字段？现成的是 `mean_cluster_w_mm` / `mean_cluster_h_mm`，
  但"长度/直径"与"宽/高"是不是同一个量，**要以测量侧的定义为准**（我不替它定名）。
- **不确定度**：每个量一个伴生列（建议 `*_sd_mm` 或 `*_ci_mm`，**并写清是标准差还是区间**——
  "±0.3"和"0.2–0.6"是两种东西，页面文案完全不同）。**没有这一列我就不显示不确定度**。
- **口径**：什么情况下是 NULL？与现有的 `no_angle_profile`（角度档缺测）、
  `no_detection`/`no_light`（帧不可用）的优先序如何？——按现有三种"空"的优先序接：
  ①有值 ②没检出/门拒 ③有检出但角度相关列/该量缺测 ④其余不可用。
- **样本量**：`n` 已经有了（契约里在），不确定度要和 `n` 一起看；`n` 很小的时候要不要弱提示，请给一句口径。

### 3.2 环境首日剔除的标记（等环境官）

要能区分三种情况，**页面不许靠猜**：
1. **本来就没有数据**（没采到）；
2. **有数据但被剔除了**（入库首日）← 这一档必须能在页面上"显式标记"；
3. 有数据且正常显示。

请求字段（形状由环境官定，这里只说语义）：
- 每条 `rows` 行能不能带一个"是否被剔除/为什么"的标记？
  或
- summary/batches 里给出**剔除区间**（如 `{"excluded": [{"reason": "first_day", "from": …, "to": …}]}`），
  页面按区间画底纹 + 「首日剔除」标注。

**关键**：光把行删掉是**不够**的——那样第 1 档和第 2 档在页面上长得一模一样。

## 4. 页面将怎么做（等契约落地后实施，先写下来免得走样）

1. **一期交付量放到最前**：环境/历史两处的测量块把"菌簇平均长度 / 平均直径"排在首位，
   **每格都必须带量纲**（`mm`，沿用 `unitLabel()`）；
2. **不确定度**只在字段存在且非 NULL 时显示，形如「24.3 mm ±1.2」（措辞按 3.1 给的口径定）；
   字段缺失或 NULL ⇒ **不显示数字**，按现有三种"空"的话术说清"为什么没有"；
3. **实测 vs 探索项**：实测值用正常字重；探索项（估算/预测）用弱化样式 + 「探索项」角标，
   并且**不进长势曲线的主线**（票面已立的规矩：两种量纲绝不画进一条线）；
4. **首日剔除**：按 3.2 的标记在曲线上画显式区间/底纹 + 「首日剔除」文字，并在图例里说明；
   拿不到标记时**照原样画**（宁可不剔，也不静默丢）——这与"没有记录 ≠ 干净"同一条原则；
5. `CONTEXT.md` 的措辞表要加"探索项"这一条，等 Chief 归一后我按它写（我不自造词）。

## 5. 可扫描断言（实现时必须逐条有）

1. **量纲跟数字走**：任何显示出来的菌簇量都带 `mm`；
2. **不确定度**：字段在场 ⇒ 有 `±`（或区间，按口径）；字段缺失/NULL ⇒ **不出现 `±` 数字**；
3. **探索项**：估算/预测量在场 ⇒ 文案含「探索项」，且**不出现在**长势曲线的主数据里；
4. **首日剔除**：给了剔除标记 ⇒ 图上出现「首日剔除」且区间与标记一致；**没给标记 ⇒ 不出现这四个字**
   （防"假装标了"）；
5. **契约三件套照旧**：新字段进 `CONTRACT` 与 `PAGE_CONSUMES`；值可 NULL 的列**不进 `required`**；
6. **负向钉子**：页面不许把 NULL 渲染成 `0` 或空串，也不许自己按 `p10/p90` 编不确定度。

## 6. 不做什么

- **不改数据**：不做服务端剔除、不改 `analysis` 的过滤逻辑（那是环境官的活）；
- **不静默丢行**：页面不为了"好看"过滤任何数据；
- **不把估算量当交付量**：不把探索项与实测值混排、不给它同等的视觉权重；
- **不自造不确定度**：契约没有就不显示；
- **不动别的领地**：本票只改 `web/console/index.html` 与 `verify-page.js`（+ 本票）。
