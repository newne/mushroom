## 0. 为什么现在只到 `needs-info`

spec §10.2 把 P2-1 写成"有数据就能训"的一步，但三个前置都还没有票、也没有产物：

| 前置 | 现在有什么 | 缺什么 |
| --- | --- | --- |
| 训练集 | 68 帧样本池的**取图清单**（票 03）；0 帧已标注 | 标注产物 + 转换后的 COCO + 侧车 |
| 标签转换 | `docs/patrol/growth-algo/tools/xlabel_coco_join/` 有 join 工具雏形 | 与 `annotation-config` 对齐的正式转换器（P1-3） |
| 预标注 | 模板映射/启发式方案写死在 §5.4 | 批处理脚本与复核页（P1-5） |

所以本票**不写"开始训练"**，先把"什么算数据齐了、训完怎么算过"写死；
数据一到位即可转 `ready-for-agent`，不必重新讨论口径。

## 1. 交付物（数据齐了之后）

1. **数据集契约**：COCO（`bag`/`cluster`/`cap`）+ 侧车（`source`、`review_status`、`group_id`、
   `association_valid`、`measurement_valid`、`baseline_valid`）；`rejected` 行必须保留。
2. **划分清单**：按 `round_id` 分组（G8），同一轮全部站位同侧；锁定测试集**从零人标**、
   **永不由被评模型预标注**；清单含哈希。
3. **训练配方**：`yolo26s-seg`，输入 = `front_roi` 裁剪，`imgsz=640` 先定参、`960` 复核；
   `workers=0`（Windows 保护）；纯 CPU；训练落点 = 开发机（22 核 / 15 GiB）。
4. **产物**：权重 + `model_version` + 训练配置快照 + `dataset_version` + 逐 epoch 曲线；
   晋级走既有 MLflow registry + stage（`src/vision/offline/promote.py`），**不新造治理**。
5. **评估报告**：锁定测试集上的检测 P/R、掩码质量（mAP50-95 mask）、粘连/拆分、
   小帽漏检；按层/光照/阶段分组；延迟 p50/p95（4 核）。

## 2. 门槛（照 §9.1/§9.5，冻结后才看锁定测试集）

| 项 | 门槛 |
| --- | --- |
| 检测 P/R（`bag`/`cluster`） | 先冻结初值，再报；**不允许只看模型自我对比** |
| 掩码质量 | mAP50-95(mask) 报绝对值和与 H2 基线差 |
| 粘连/拆分 | 合并实例必须能被识别（`merged_multiple_bags`），不得静默拆 |
| 归属可用性 | 输出实例必须能支撑 L3 一袋一簇；歧义率单列 |
| 延迟 | 单帧 ≤3.75 s（含预处理，4 核口径） |
| 机时 | 600 帧 × 50 epochs ≈ 8.7 h（`imgsz=640`）；超预算必须写原因 |

## 3. 验收（缺一条不算过）

- [ ] `dataset_version` 能回答"这个模型是哪些帧训出来的"（帧清单可 join）
- [ ] 锁定测试集与训练集 `round_id` 零交集；锁定集 `source` 只有 `human_added`
- [ ] 训练集里没有"被本模型预标注后未复核"的行（`review_status=predicted` 必须为 0）
- [ ] 权重、配置、数据集清单三者哈希互相对应，可复跑
- [ ] 评估脚本只读锁定测试集，输出逐项误差 + 有效率，不只报一个总分
- [ ] 晋级只看锁定测试集；不达标**只入库、不晋级**
- [ ] 不写 mm、不改 DDL、不动生产开关

## 4. 不做什么

- **不在数据齐之前训练**（本票现在只做契约与门槛）
- 不做 GPU、不做在线推理服务
- 不把票 17 的评测集当训练集（会污染 §9.5 的对照）
- 不做第二套模型治理
