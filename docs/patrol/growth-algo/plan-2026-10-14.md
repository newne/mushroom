## 1. 项目目标与交付边界

### 1.1 已知场景
- 4 层架子，每层 12 个拍照锚点，共 **48 个固定观察位置**；同一锚点持续采集，可形成时间序列。
- 图像中菌杆密集、遮挡明显 ⇒ **单杆识别与完整杆长测量不作为本期目标**。
- 主分析对象为**前排菌包及其菌簇**；**后排不参与量测**。
- 部分阶段尚未分化出明确菌帽 ⇒ **不强行输出帽径**。
- 通用预训练权重**不能**直接作为现场识别结果 ⇒ 需真实现场标注与训练。

### 1.2 分期交付

| 分期 | 交付内容 |
| --- | --- |
| 主交付 | 菌包定位、一袋一簇、菌簇**平均轮廓高度**、顶部高度、宽度及时间曲线 |
| 增强交付 | 可辨认菌帽的实例分割、投影直径分布及时间曲线 |
| 后续解锁 | 经独立验证的毫米换算 |
| 本期不做 | 单杆完整测量、遮挡补全、全场真实朵数、单杆跨日增长、产量推算 |

**菌簇高度不是平均菌杆长度；菌簇宽度不是菌帽直径。**

## 2. 总体架构

```
原始图像与采集索引
  → 锚点、周期、轮次身份检查
  → 内容完整性与图像质量检查
  → 锚点参考图对齐
  → 菌包／菌簇定位模型
  → 前排模板过滤与一袋一簇关联
  → 逐包原图裁剪
      ├─ 菌簇掩码 + 袋顶基线 → 簇级量测
      └─ 菌帽实例模型 → 可测帽径
  → 逐袋结果、质量状态与证据
  → 固定菌包集合聚合
  → 单锚点曲线
  → 单层 12 锚点与四层趋势总览
```

采集与分析解耦；基础（簇级）与增强（帽径）分支独立——**菌帽模型不可用时不阻塞菌簇曲线**。

## 3. 模型与处理方式

| 模块 | 建议方案 | 角色 |
| --- | --- | --- |
| 前排 ROI | 每锚点人工模板 + 对齐映射 | 限定持续观察范围 |
| 图像对齐 | OpenCV ECC，**平移优先** | 消除小范围机位漂移 |
| 菌包／菌簇定位 | 专用 **YOLO26s-seg** | 输出框、掩码、置信度 |
| 菌簇局部精分割 | 先复用定位模型；不足时独立训练簇模型 | 改善顶部轮廓 |
| 袋顶基线 | 人工参考折线 + 映射 + 有效性检查 | 定义高度起点 |
| 菌帽分割 | 独立 YOLO26s-seg | 单帽可见掩码 |
| 辅助标注 | SAM 2.1 + 人工修正 | 降低标注成本 |
| 量测 | 掩码轮廓、基线、几何算法 | 计算像素指标 |
| 时序分析 | 固定集合、分段、原始点 + 可选平滑 | 生成可信曲线 |

- YOLO26-seg 支持自定义训练、实例掩码输出与模型导出；预训练权重只作**初始化**。
- OpenCV ECC 先限制为**平移**，验证后再考虑小角度旋转；**不默认用透视变换**修复明显视角变化。

## 5. Offline 标注方案

### 5.1 环境
- 建议内部自部署 **CVAT**：图片、标注、权重、训练结果留在内部环境；官方支持本地容器部署与多边形/掩码/属性/导出。
- **自部署 ≠ 断网可用**：若要求完全断网，需单独准备并验证镜像、依赖、权重与前端资源。

### 5.2 标注对象

| 对象 | 形式 | 关键规则 |
| --- | --- | --- |
| 前排 ROI | 锚点模板多边形 | 不逐帧随检测结果改变 |
| 菌包 | 可见框 + 掩码 | 不包含上方菌簇 |
| 菌簇 | **一袋一实例**的可见掩码 | 不分单杆、不填满内部背景 |
| 袋顶基线 | 折线 + 有效性 | 不可见时不猜 |
| 菌帽 | 单帽可见掩码 | 不补全遮挡轮廓 |
| 不可判定区域 | 区域 + 原因 | 保留模糊、粘连、归属歧义 |

- 菌簇跨袋归属不明确 ⇒ 标**不可靠**；菌帽未明显分化 ⇒ 记录状态，**不生成虚构菌帽**。

### 5.3 标注属性

`bag_group_id` 表达**同帧归属**，不自动表达跨日身份。

### 5.4 数据采样（优先覆盖）
4 层 48 锚点；不同生长阶段；稀疏/密集/倾斜/跨袋菌簇；清晰/低对比/反光/模糊/截断；袋顶清晰与遮挡；菌帽可辨认/未分化/不可判断；空袋、包装亮斑等**困难负样本**。
⇒ 先形成覆盖 48 锚点的代表样本池，再按**模型失败类型**扩充；**不承诺固定帧数即可满足训练要求**。

### 5.5 质检与数据划分
- 小批样本**双人独立标注**，重点查：一袋一簇归属、菌簇顶部轮廓、袋顶基线、菌帽身份与测量资格。
- 先按**周期/锚点/时间块**分组，再裁剪；断言无源图重叠、无近重复泄漏：
```

for image in images:
    for crop in create_crops(image):
        crop.split = split[image.group_id]

```
- 两类测试：已知锚点不同时段 / 未见锚点或独立批次。**锁定测试集不用于调参**；标注主档案保留无损掩码与元数据，转格式后必须回读检查。

## 6. 图像质量与对齐

### 6.1 质量门（在目标 ROI 内计算）
暗像素与饱和像素比例、清晰度、目标截断比例、内容完整性、稳定背景亮度变化。
重复图 = **图像哈希 + 采集元数据**共同判断，不凭相似度拒绝短间隔的真实图像。

### 6.2 对齐策略
用货架等**稳定背景**；**不以正在生长的菌簇**作为唯一对齐依据；低分辨率估计变换 → 映射 ROI → **在原图坐标量测**。
```
def register_frame(current, template):
    T, diagnostics = estimate_ecc(reference=template.reference_image,
                                  current=current,
                                  static_mask=template.static_background_mask,
                                  motion="translation")
    if not diagnostics.converged:            return reject("registration_failed")
    if not within_validated_transform_limits(T): return reject("view_changed")
    if not residual_acceptable(diagnostics): return reject("registration_unreliable")
    return accept(T)      # 参考图坐标 → 当前原图坐标
```
用**已知平移**测试验证矩阵方向、缩放与坐标还原；**对齐分数不得作为唯一放行条件**。

## 7. 菌包／菌簇模型与归属

### 7.1 模型 A
首选专用 YOLO26s-seg；对照更大模型；类别 `bag`、`cluster`；预训练初始化；训练数据 = 人工确认的现场图。**模型规模/输入分辨率/裁剪方式由开发集比较决定**，不以最大模型为默认。

### 7.2 前排过滤
```
objects   = model_A.predict(original_image)
front_roi = map_roi(template.front_roi, registration.T)
bags      = filter_objects(objects.bags, front_roi)
clusters  = filter_objects(objects.clusters, front_roi)
```
后排不参与量测，但**训练中必须明确其处理方式**，不得把未标注对象无意当背景。

### 7.3 一袋一簇关联
依据：菌簇下缘与袋顶关系、横向重叠、锚点菌包槽位、最近与次近候选的歧义。
```
pairs = one_to_one_match(bags, clusters,
        cues=["bag_top", "cluster_lower_edge", "horizontal_overlap", "slot_membership"])
for pair in pairs:
    if pair.ambiguous or pair.truncated:
        pair.measurement_valid = False
```
不要求菌簇掩码位于菌包掩码内部，**不只按水平最近归属**；模型把多袋菌簇合并为一个实例 ⇒ 标**关联失败**，**不强行分摊尺寸**。

## 8. 菌簇高度与形态量测

### 8.1 主指标：平均轮廓高度
对每袋：取可靠袋顶基线 b(x)、菌簇顶部轮廓 t(x)，在有效横向位置计算 h(x)=b(x)−t(x)，取均值
`H_profile = (1/|V|) Σ_{x∈V} [b(x) − t(x)]`，V = 顶部轮廓与基线均可靠的位置集合。
**该指标表示菌簇平均顶部轮廓高度，不表示平均菌杆长度。**

### 8.2 辅助指标
稳健顶部高度、原始最高点高度、菌簇横向投影跨度、固定 ROI 内可见菌体覆盖率、有效轮廓列比例。
```
def measure_cluster(mask, baseline, config):
    if not baseline.valid: return missing("baseline_invalid")
    heights = []
    for x in supported_columns(mask):
        top  = reliable_top(mask, x, config)
        base = baseline.at(x)
        if top is not None and base is not None:
            heights.append(base - top)
    if not sufficient_column_coverage(heights, config):
        return missing("insufficient_contour")
    return {"mean_profile_height_px": mean(heights),
            "robust_top_height_px":   quantile(heights, config.top_quantile),
            "raw_top_height_px":      max(heights),
            "cluster_width_px":       validated_width(mask, config),
            "valid_column_count":     len(heights)}
```
分位数、噪点处理、有效列规则在开发集确定后**冻结**。

### 8.3 袋顶基线处理
第一版用**人工参考折线**，经对齐映射后逐帧验证：菌包是否仍在原槽位、袋口是否移动/形变、基线是否被遮挡、是否仍对应同一物理位置。
不可靠 ⇒ 高度**缺测**；菌簇自身竖向跨度可另存，**但不能替代同名基线高度**。

## 9. 菌帽投影直径（增强项）

### 9.1 模型 B
独立训练菌帽实例模型：输入单包原图裁剪，类别 `cap`，输出单帽可见掩码 + 置信度。**未分化或不可判断阶段不解锁帽径。**

### 9.2 测量资格
仅纳入：单帽身份明确、轮廓足够完整、未被图像边界截断、未明显合并多个帽、人工定义的测量资格通过。第一版统一采用**最大投影卡尺直径**，单位 px。
```
def measure_caps(crop, coordinate_map):
    predictions = model_B.predict(crop); values = []
    for cap in predictions:
        if not cap_measurement_eligible(cap):
            save_rejected_cap(cap); continue
        contour = coordinate_map.to_original(cap.contour)
        values.append(maximum_projected_caliper(contour))
    return {"mean_cap_projected_d_px":   mean_or_null(values),
            "median_cap_projected_d_px": median_or_null(values),
            "valid_cap_count":           len(values),
            "rejected_cap_count":        count_rejected(predictions)}
```
无合格菌帽 ⇒ 直径 **NULL**；**只有完成有效观察且确认无菌帽，计数才可为 0**。帽径均值代表**可测菌帽样本**，不自动代表全部菌帽。

## 10. 尺度与单位策略
**第一版主交付**：原图像素高度、原图像素帽径、无量纲覆盖率、同锚点相对基准变化。
**毫米解锁条件**（全满足才可出 mm）：参考物实际尺寸与可见边界确认；参考物检测稳定；参考物与目标几何适用条件明确；缩放/畸变/内参处理确认；**独立量测误差通过**。
- 相机投影涉及内参、深度、外参；**方形像素不能单独证明各方向共用同一物理尺度**。
- **不采用未经验证的统一倍数修正或通用角度补偿**；逐袋尺度保留逐袋证据，**不用一个帧级尺度替代全部袋**。

## 11. 锚点时序与四层汇总

### 11.1 固定菌包集合
每锚点建立周期内**固定观察集合**：主趋势用稳定集合；缺袋时记录覆盖率；样本组成明显改变时曲线标记不可比或分段；可另附"当次全部有效袋"统计但与主趋势**分开**。
```
def aggregate_anchor(bag_results, fixed_panel):
    matched = match_panel(bag_results, fixed_panel)
    if not panel_coverage_acceptable(matched): return missing("panel_coverage_low")
    return {"mean_cluster_height_px":   mean_valid(matched, "mean_profile_height_px"),
            "median_cluster_height_px": median_valid(matched, "mean_profile_height_px"),
            "valid_bag_count":          count_valid(matched),
            "panel_coverage":           coverage(matched),
            "cap_summary":              aggregate_valid_caps(matched)}
```

### 11.2 曲线规则
用**采集时间**不用处理时间；保留原始点；平滑仅用于展示；**缺测不补成实测值**；**不跨长缺测区间计算变化速率**；不强制单调增长；换包/视角/版本变化时**分段**。
```
segments = split_series(observations,
    by=["cycle_id", "pipeline_version", "roi_version", "calibration_version"],
    events=["replacement", "view_change"])
for segment in segments:
    raw = retain_raw_points(segment); valid = select_comparable_points(raw)
    trend = optional_display_smoothing(valid); rate = compute_valid_pair_changes(valid)
```
群体指标变化称为**簇级形态变化**或**可测帽径分布变化**，**不称为同一蘑菇增长**。

### 11.3 四层总览
每层 12 锚点小图曲线；有效锚点数与缺测；各锚点相对自身基准变化；层内趋势中位数与离散范围；**质量异常与形态变化分别标记**。
相邻锚点可能拍到同一菌包 ⇒ **未经去重不能累加为全层数量**。

## 12. 结果、证据与契约

### 12.1 三层证据
| 层级 | 保存内容 |
| --- | --- |
| 帧级 | 原图 ID、锚点、周期、质量、对齐、版本 |
| 袋级 | 掩码、归属、基线、簇指标、有效性 |
| 帽级 | 掩码、直径、资格、拒绝原因 |

每个曲线点可追溯到原图、掩码、基线与算法配置。

### 12.2 现有数据库适配
- **像素值不写入毫米列**；菌簇数/菌帽数**不写成总朵数**；NULL = 未知或不可测，**0 只表示已确认的零**；检测失败与尺度失败**分开**；一袋失败**不清空**其他可靠袋；统一检查 **输入数 = 成功数 + 失败数 + 跳过数**。
- **现有契约不能表达的新指标先进入离线证据与结果文件，数据库变更另行评审。**

## 13. 主流程伪代码
```
def process_observation(meta, pipeline):
    key = make_result_key(meta, pipeline)
    if result_exists(key): return load_result(key)

    image    = decode_original(meta)
    template = load_anchor_template(meta.anchor_key)

    quality = assess_quality(image, meta, template)
    if quality.blocked: return persist_failure(key, quality.reasons)

    registration = register_frame(image, template)
    if not registration.accepted: return persist_failure(key, registration.reasons)

    front_roi = map_roi(template.front_roi, registration.T)
    objects   = pipeline.locator.predict(image)
    pairs     = associate_front_bags_clusters(objects, front_roi, template.bag_slots)

    results = []
    for pair in pairs:
        if not pair.reliable:
            results.append(invalid_pair(pair)); continue
        crop, mapping = crop_original(pair, image)
        cluster_mask  = obtain_cluster_mask(pair, crop, pipeline)
        baseline      = map_and_validate_baseline(pair, template, registration, image)
        cluster_result= measure_cluster(restore_mask(cluster_mask, mapping), baseline,
                                        pipeline.measure_config)
        cap_result = None
        if pipeline.cap_model_available:
            cap_result = measure_caps(crop, mapping)
        results.append(build_bag_result(pair, cluster_result, cap_result))

    evidence = save_evidence(meta, registration, results, pipeline)
    summary  = aggregate_anchor(results, template.fixed_panel)
    return persist_result(key, summary, evidence)
```
**所有抽象函数都需明确输入、输出、坐标系、失败状态与单元测试；不允许 agent 以默认值静默补齐。**

## 14. 评估与验收

### 14.1 独立评价项
| 模块 | 指标 |
| --- | --- |
| 菌包／菌簇 | 检测 P/R、掩码质量、粘连与拆分 |
| 归属 | 一袋一簇匹配正确率、歧义比例 |
| 基线 | 人工折线偏差、有效率 |
| 簇高 | 像素误差、有效袋比例、顶部轮廓覆盖 |
| 菌帽 | 实例 P/R、合并、直径误差、有效帽比例 |
| 时序 | 静态重复性、事件分段、缺测处理 |
| 系统 | 完整 48 锚点耗时、内存、重试、结果完整性 |

**同时报告误差与有效率**，按层/阶段/质量类别分组。

### 14.2 三类必要测试
1. **静态重复测试**：不应产生明显虚假增长；
2. **真实变化测试**：人工对照图像与曲线方向；
3. **中断事件测试**：换包、缺图、偏移、模型升级不错误连续。

数值门槛在开发集分析后、**查看锁定测试结果前冻结**；出值率、量级、跑通**仅作工程检查**，不替代精度。

## 15. 实施阶段与停止条件

| 阶段 | 交付物 | 进入下一阶段条件 |
| --- | --- | --- |
| P0 | 身份、模板、指标、标注规范 | 定义无歧义 |
| P1 | Offline 样本与人工复核 | 簇归属、基线、帽资格一致 |
| P2 | 菌包／菌簇模型 | 真实测试满足定位与归属要求 |
| P3 | 簇高量测与单锚点曲线 | 误差、有效率、重复性通过 |
| P4 | 48 锚点覆盖 | 各层代表场景稳定 |
| P5 | 菌帽模型与帽径曲线 | 可辨认样本与量测证据充分 |
| P6 | 标定与生产适配 | 尺度、契约、性能通过 |

**停止/降级规则**：菌簇归属不清 ⇒ 不出该袋指标；袋顶不可靠 ⇒ 基线高度缺测、另存簇跨度；菌帽不可辨认 ⇒ 不出帽径；视角不可比 ⇒ 不连接趋势；尺度未确认 ⇒ 不出确定性毫米值；**模型误差主要来自图像信息不足 ⇒ 改采集，不继续堆模型**。

## 16. 推荐落地组合
- **主交付**：内部离线标注 → 菌包／菌簇专用模型 → 前排过滤与同袋关联 → 袋顶基线 + 平均轮廓高度 → 48 锚点时序曲线。
- **增强交付**：可辨认菌帽离线标注 → 独立帽实例模型 → 投影直径与有效样本数 → 帽径分布曲线。

> 本 Plan 将**真实现场标注、明确量测定义、时序可比性**作为核心；保留模型初始化与辅助标注的价值，但不依赖通用权重直接解决现场识别。**先形成可信簇级趋势，再解锁菌帽与毫米量**，避免再次把菌包尺寸或菌丛跨度误交付为单杆长度。
