# 25. 每轮环境快照（键 = 巡检轮次）

Status: ready-for-agent
归属：后端
依据：`docs/patrol/env-baseline/spec.md`（每轮快照）；D19
依赖：22（调控维）

## 1. 交付物

1. **每轮一条（房间级）**，键 = 巡检轮次 ID；同时给 `ts` 与对齐用的小时
2. 三维（温度 / 湿度 / CO₂）的 mean / min / max / **采样点数 n**
3. 调控维（来自 22）＋ 该小时的**设定末态**
4. 批次与生长天数；缺小时的轮次标 `comparable=false`

## 2. 验收（缺一条不算过）

- [ ] 可按巡检轮次取到
- [ ] **采样点数 n 必须带上**（不足 60 即该小时有缺口，可审计）
- [ ] 缺小时标不可比，**不补邻近小时**
- [ ] 算法侧可按同一个键关联生长曲线

## 3. 不做什么

- 不做每站一条（环境是房间级量，48 站重复是冗余）
- 不做插值
