## 为什么必须标定

真机帧 `data/S306-candidate-Y2058.833-Z117.5-20261008.jpg`（1343×754）实测
`laplacian_variance = 70.8`，而 `measure/quality.py` 的默认模糊阈值是 **100**
⇒ **现役默认门会把真机帧判为"模糊不可用"**。平视单档 + 矮菇（用户口径：第 13 天、
菌杆矮且无帽）本身就是低纹理画面，拍脑袋定的常数 100 在这里大概率过严——
但也不能顺手调小：**阈值决定"哪些帧进测量"，调错等于给整条生长曲线换口径。**

## 要什么样本（找发版官，只读抽取）

**抽样设计（Chief 2026-10-13 要求写全）**：总量 ≈ **200 帧**，按下表分层，
每格独立标注、不混池统计。

| 层 | 维度 | 每格样本量 | 说明 |
| --- | --- | --- | --- |
| L1 跨轮次 | 同一天内 **≥3 轮**（每 3 小时一轮，间隔 ≥3h） | 每轮 ≥10 帧 | 例：早/午/夜灯窗各一轮，看灯窗内照度是否稳定 |
| L2 跨天 | **≥3 个不同日期** | 每天 ≥10 帧 | 看相机白平衡/曝光是否漂移 |
| L3 跨生长阶段 | 当前（第 13 天前后，菌杆矮无帽）+ 之后长高后各一批 | 每阶段 ≥20 帧 | 纹理量会随生长变化，**这是"多保守"的主要依据** |
| L4 跨站位 | 至少覆盖 **4 个层 × 3 个列**（含最左/最右列） | 每站位 ≥2 帧 | Z 不同层照度不同；最右列离补光灯最远 |

**已知坏帧对照（每类 ≥10 帧，必须真样本，不接受合成）**：

- **加湿期**帧：保持期内 + 保持结束 +20 分钟附近各取几帧（CONTEXT.md:22：水汽重、过曝、
  对比度低）；
- **灯未亮/近黑**帧：灯窗外的帧、或采图时补光灯没点的帧（`no_light` 的正样本）；
- **预览/低分辨率**帧：`/api/patrol/preview` 那条 1280×718 的流（**不进历史**，
  但若被误当测量帧要有判据拦住）；
- **失焦/抖动**帧：换角或重新固定支架后的头几帧、以及任何人工标记"拍糊了"的帧。

**交付形态**：一个目录 + `labels.csv`（`file,label`，label ∈
`ok / blurry / overexposed / dark / preview / unknown`），保留文件名里的
`station_id / angle_profile / ts`；**脱敏**（不带凭据、不带 URL）。

## 要产出的东西

1. **分布统计**：`laplacian_variance`、`overexposed_fraction`、`p99_brightness`
   （近黑判据用的是 p99，不是均值——真机帧强晕影下均值会误判），按 label 分组给
   p10/p50/p90 与直方图，把"ok 与 bad 的分界"画出来；
2. **三组候选阈值** + 理由：
   - 模糊阈值：以 **ok 的 p10**（或更保守的 ok 最小值）为下限参考，取"尽量不误杀 ok、
     又能拦住已知坏帧"的值；
   - 过曝比例阈值：同理（现默认 0.05）；
   - 近黑阈值：现默认 `p99 < 0.12`（占位），用 `dark` 与 `ok` 两组的 p99 分布定界；
3. **处置口径（已裁定，标定只需复核一致性）**：模糊 / 过曝 / 近黑 ⇒ **不可用**
   （`frame_quality` 返回 False ⇒ 不产行）；其余不确定情形 ⇒ 产行 + `low_confidence`。
   **门只决定 `verified` 的授予，不决定入库**——被拒帧要留在库里可审计。
4. **风险记账（环境官 2026-10-13 提）**：若门把绝大多数真机帧都拒了，`verified` 就没有
   样本、区间表照样空（只是"诚实的空"）。所以**定标与票 05 一起排**，标定完成前
   **宁可偏保守**（多标 `low_confidence` 无害，因为它不进统计）；
5. **回归**：把 `data/S306-...jpg` 作为已知帧进单测（`lapvar` 具体值 + 门判定结论），
   保证阈值以后改动时"为什么改"可复现。

## 标定结论（2026-10-13，样本落地后）

**样本**：发版官只读抽取 **230 帧**（`.scratch/frame-quality-samples/`，编号/规模见其交付说明）。
分层实际条数：`L1_round 36 / L2_day 24 / L3_stage 24 / L4_station 24 / pair 24 / preview 10 / fill 88`；
`label_auto` 分布：`ok 218 / dark 2 / preview 10`。
**独立复算**：测量师用 `measure.quality` 自有函数在原始帧上重算，与样本表逐帧一致
（`lapvar` 与 `p99` 都对得上）⇒ 标定用的量与线上判据同源同刻度。

### 刻度（先说清，否则阈值无意义）

`lapvar` 在 **0–255 灰度**上算（`np.asarray(img).mean(axis=2)`）；在 0–1 上算会小 65025 倍。
`p99_brightness` 内部归一到 0–1。

### 三条阈值

| 判据 | 定标值 | 依据（218 张 `ok` 为正常人群） | 误杀率 |
| --- | --- | --- | --- |
| 清晰度绝对下限 | **45.0**（0–255 刻度） | `ok` 的 `lapvar` min=48.0、p05=52.6、p10=53.7、p50=71.3 | **0/218** |
| 近黑 `no_light` | **p99 < 0.12**（0–1） | `ok` 的 p99 min=0.722；两张真暗帧 p99=0.008/0.012（余量两侧 >6 倍） | **0/218** |
| 过曝 | 维持 0.05 | 全样本 `overexposed_frac` **全为 0.00** ⇒ 这批样本定不了它 | 0/218 |

**关键发现（推翻旧默认）**：旧默认模糊门 **100 会拒掉 78.4%（171/218）的正常真机帧**，
且 `ok` 的**中位数 71.3 本身就低于它**。所以旧 100 不是"严格"，是**错的尺度**——
平视单档 + 矮菇本身就低纹理。已把默认值改为上表并写进 `measure/quality.py` 的注释
（含"换角/换灯后必须重算"的提醒），标定脚本 `measure/tools/calibrate_quality_thresholds.py`
可复跑，回归测试 `measure/tests/test_quality_calibration.py` 钉住结论（样本不在则 skip）。

**"模糊/过曝"两类坏帧的样本问题**：池子里 `blurry`/`overexposed` **各 0 帧**——
不是抽样失手，是历史上没发生过（或发生后没被记录）。⇒ 这两类**不能靠度量从历史里捞**，
需要按**已知事件**定向取（换角/重固定支架后的头几帧、人工标"拍糊了"的），
或等真实坏帧自然出现后补。**在补到之前，`blur` 判据的"漏杀率"无法测量**，
只能保证"误杀率"为 0。

**相对判据的前提已用 `pair` 层验证**：同站位跨轮次两轮的 `lapvar` 相对差
**min 0.4% / p50 1.2% / max 4.2%**（12 站位）——同一站位跨轮很稳，
而站位之间（44.9–182.8）差异大得多。这正是"相对化"能成立、且必须按站位分组的依据。

**preview 层**：`lapvar` p50=80.62、p99 p50=230——与正常帧**没有可分性**，
所以"拦 preview"不能靠图像判据，只能靠来源标记（`source=preview_frame`）。
本层**不参与阈值拟合**。
